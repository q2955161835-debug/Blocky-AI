## 界面依据与演示边界

当前已发布 `Blocky-Studio-0.8.0-beta.1-final` 及对应桌面源码是界面基准。对应桌面源码的 `app/App.tsx`、`Library.tsx`、`StudioSidebar.tsx`、`BuilderPanel.tsx` 提供壳布局依据，实际画布与积木定义直接导入复用。灰蓝配色、单行图标栏、七/十二分类、嵌套积木、可调宽度三栏、默认收起底栏、右侧聊天均按此基准。

网站额外提供一条体验说明/返回官网栏；窄屏以积木库、画布、对话切换访问同一工作区。对话、轨迹和运行结果为预设；文件、模型和部署入口仅说明桌面版能力，不操作本机文件。输入只存在当前 iframe 内存，离开后销毁。CSP 禁止 connect-src、media、表单提交，不加载运行内核或真实模型配置。

## 发布与核对

版本22构建输入由 `build-inputs/quiz-v22/manifest.json` 封存：共享积木注册、画布组件、画布样式与积木目录共4份，逐SHA绑定已验产品644fd89。`build-inputs.mjs` 在esbuild加载原模块路径时提供这些文本，保留原相对依赖和许可证；损坏输入立即失败。这样主线可重建与发布完全相同的52资源，同时桌面返修继续在其任务分支。后续官网升级共享前端时，应重新生成清单并验证，不把此清单用于桌面构建。

在线体验另有“工作助手 · 1分钟演示”：固定提示词→逐步搭建真实蓝图结构→自动切换Agent→预设读取/计算/生成/读回周报，60秒结束。所有工具轨迹及文件结果均为合成示例，不产生外部副作用。剧情和调度拆分在 `experience/guided-demo/`，中英文本在 `dist/demo-translations.js`；播放支持暂停、退出恢复原项目、重播及完成后继续编辑。计时不受语言/主题切换重置。

Sites继续使用原生工作流，只发布 `dist/` 和托管清单。GitHub Pages以 `gh-pages` 根目录的同一静态资源托管，不需要Jekyll、桌面构建或真实模型服务；官网更新后需重新同步该发布分支，快进保留发布历史，随后核对部署成功与线上资产来源。两种托管均只发布公开网页和许可证，工程记录不进入网页目录。根GitHub文档合并/推送另行处理，验收与回执见 `doc/验收/网站/`。当前组件复用避免再次手绘积木；网站适配壳仍需随桌面主要布局变化维护。
