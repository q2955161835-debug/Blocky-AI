## 素材与证据边界

- 44秒角色动画采用六个本机 MiniMax 镜头；统一3D首帧后串行请求0.25MP/8步，五次6秒、一次8秒。实际672×384/24fps，前五段6.583333秒、末段8秒。成片放大至1080p，源细节受生成分辨率限制；末段复用3.8–8秒并以0.7倍速收尾。
- Codex 外形以用户截图为准；Clawd 采用常见棕橙像素轮廓并增加体积、材质和接触阴影。[形象来源](assets/references/来源.json)单独保存。三人协作是虚构动画，不宣称厂商官方原生集成或本轮实际调用 Codex/Claude Code。
- `sources/ui/blocky-nested-review-edit.mp4`是当前真实前端13块嵌套结构及实际字段提交；`blocky-preset-runtime-highlights.mp4`复用现有官网预设模拟，不是本轮真实模型/桌面Runtime执行，片内标明“界面演示”。
- 隔离目录真实CLI create/map成功；validate/compile缺模型配置失败，simulate因provider禁用失败，原结果保持。虚拟协作层仅采用核对过的创建命令，片内标明“CLI协作情景示意”。
- 所有源视频嵌入声降至-60dB；采用原创60秒120BPM配乐与ChatCut两种喜剧音效，抑制片段无关语音。该参数为强衰减，不证明数字零音量；无旁白，制作工具未确认真人听感或源语音完全无残留。
