一分钟荒诞喜剧试片。核心：**自己的 AI，自己改。**

## 创作方向

冷开场：太空办公室，电话照样催活。倒回普通工位，逐级兑现“卷一下”“躺平”“起飞”的字面含义。三次视觉升级之后，打断、停顿，转到 Blocky 的可见积木结构和真实字段改造，回到正常工作，落版。

沿用品牌蓝色双凸点角色、黑色豆形眼和黄绿点色；场景采用有实体细节的微缩摄影，剪辑由 ChatCut 保留多源、多轨、可改字幕和音轨。文字均在剪辑阶段叠加。热梗采用“内卷/躺平/起飞/不是哥们”的语境，不把某个词宣称为当日排行榜热门。

参考方法来自项目内 Scenario Inspiration / Video Ads / Storyboards 技能（MIT）：发散变换、熟悉语义的意外兑现、升级冲突、反应镜头、最后用一个产品真相收束。实际视频使用本机 MiniMax 工作流，剪辑使用 ChatCut。

ChatCut 项目：https://app.chatcut.io/zh/editor/d0cba719-b937-45cd-b22e-829476adff1d

## 生成配置与边界

先测已有 Spectrum，发现 FinalLayer 接口不兼容后保留失败记录；不升级或改写本机节点。采用原有标准首帧工作流的本轮候选，0.15MP / 8 步 / 单镜头 4–6 秒，GPU 串行；各镜头固定人物描述与关键帧，原始工作流不变。首个 4 秒请求实测服务执行 98.84 秒，取回后再检查画质及实际媒体长度。提高分辨率并不作为无依据的质量修复。

assets 是首帧素材；workflows 是提示词；sources 是忽略的原生镜头素材；outputs 是忽略的最终导出。回执与时间线来源进入本轮验收证据；脚本、日志位于 try/宣传片重制-2026-10-12。
