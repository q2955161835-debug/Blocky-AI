# 《改一块，世界就变》试片工程

用户于 2026-10-12 选择该创意并要求先做一版试片。只讲“像搭积木一样亲手改造自己的 AI”，不加入蓝图或功能清单。

## 试片范围

- 约 60 秒、16:9、1920×1080、30 fps、无旁白。
- 重复撞墙 → 察觉循环 → 拉远揭示巨大 C 形积木 → 换块 → 房间展开成阶梯 → 实际前端积木编辑 → 品牌落版。
- 角色和几何复用 `官网/art/`；网页动画与离线逐帧渲染使用现有 Three.js / playwright-core；MiniMax 使用用户现有本地首帧工作流，独立保存候选而不改原工作流。
- 结尾采集实际前端编辑；不以预设网页回复作为真实模型或 Runtime 执行证据。
- 成片为创意试片，用户对视觉方向的反馈仍是后续制作依据。

## 文件布局

- `src/`：场景、镜头和字幕源。
- `scripts/`：渲染、音轨合成和视频封装。
- `outputs/`：MP4、封面和可播放预览（生成资产，不提交 Git）。
- `../../try/待清理/宣传片试制-2026-10-12/`：模型候选、帧缓存、原始日志与过程证据，同盘可逆整理，见正式整理回执。

不安装新依赖，不更改产品、网站部署或本机 Blocky 卸载状态。所有制作源和正式记录进入 Git；生成产物有来源清单与 SHA256。

## 草拟验收范围

用户已于本轮确认这三项范围及独立视听制作验收角色。独立角色从观众视角检查：

1. 创意与节奏：前几秒出现反常现象，巨大积木揭示和换块因果清楚，核心信息集中。

## 制作与复用

在项目根目录运行，复用既有 Node、playwright-core、Three.js 和 ComfyUI Python 环境：

```powershell
node '宣传片\改一块\scripts\render.mjs' capture-ui
node '宣传片\改一块\scripts\render.mjs' boards
node '宣传片\改一块\scripts\render.mjs' render
& 'D:\Miniconda\envs\comfyui\python.exe' '宣传片\改一块\scripts\audio.py'
node '宣传片\改一块\scripts\assemble.mjs' '<本地角色反应MP4的完整地址>'
```

`workflows/` 保留本次本地首帧工作流候选及提示词。执行候选时先使用官方 Comfy CLI 发现槽位、上传当前首帧、校验并提交一次，保持 prompt_id；不改用户原工作流，不重复提交正在运行的任务。默认 5 秒、20 步和 0.4 百万像素保持原值；宽高比按本片改为 16:9，输出实际 864×480/24fps/5.167 秒，剪入 9–14 秒并合成为 1080p/30fps。全片音轨采用本工程原创程序化配乐和塑料积木音效，候选原声不进入成片。

本轮结尾为真实 Blockly 前端将回答方式从“段落”改为“条目”的编辑采集，未执行或暗示网页预设模型/桌面 Runtime 运行。

成片、封面、播放器位于 `outputs/`；冻结清单、来源与独立报告位于 `doc/验收/任务/宣传片试片证据/` 及本次验收文件。视频内不包含工程说明或过程材料。
