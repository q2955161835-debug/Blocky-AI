# Blocky 秋叶课堂讲解 Agent：60 秒录屏剧本

## 录制前状态

1. 保持 Blocky 窗口最大化，并已打开 `Blocky-秋叶课堂讲解-Agent.blocky`。
2. 画布完整显示“秋叶课堂讲解 Agent”积木链，右侧停留在“对话测试”。
3. 输入框为空，鼠标停在输入框附近；录制范围只包含 Blocky 窗口。
4. 不在录制中打开菜单、切换窗口或讲解技术实现，确保一次输入、一次运行完成演示。

## 唯一提示词

> 叶子为什么会在秋天变红？请用三句话解释，标出课程资料中的依据；资料没有说明的内容请标注“待核实”。

## 时间轴与口播

| 时间 | 屏幕操作 | 建议口播 |
|---|---|---|
| 0–6 秒 | 画面保持在完整 Agent 积木链。 | “这是 Blocky Studio。老师可以像搭 Scratch 一样，把一个课堂讲解 Agent 直接组合出来。” |
| 6–14 秒 | 单击右侧输入框，粘贴唯一提示词。 | “学生现在提问：叶子为什么会在秋天变红？回答必须引用课程依据，资料没有覆盖的内容要明确标注。” |
| 14–17 秒 | 按 Enter 发送，不再进行其他操作。 | “发送后，Agent 从课程问答入口开始运行。” |
| 17–26 秒 | 等待积木依次绿色高亮，鼠标不要遮挡画布。 | “运行过程直接映射回积木，哪一步正在执行一目了然。” |
| 26–45 秒 | 回答出现后，鼠标依次轻指 `[《秋天的叶子》§2]`、`[§3]` 和“待核实”。 | “回答不仅解释叶绿素和花青素，还标出了课程资料依据；资料没有给出的具体温度，没有被编造，而是标记为待核实。” |
| 45–55 秒 | 保持完整画面，不再点击。 | “这就是 Blocky：把 Agent 的搭建、运行和可解释结果放在同一个可视化工作台里。” |
| 55–60 秒 | 停留 1–2 秒后结束录制。 | 无需补充口播。 |

## 预期回答

> 秋天气温降低、日照时间变短后，叶绿素会逐渐分解，原本被遮住的色素开始显现。[《秋天的叶子》§2]部分树种还会积累花青素，所以叶片会呈现红色。[§3]叶片开始变红的具体温度，课程资料没有说明，待核实。

## 录屏通过标准

- 总时长不超过 60 秒，且只有一次提示词输入和一次运行。
- 输入文字、画布高亮、最终回答三个关键画面均清晰可读。
- 录制结束前同时保留积木链和完整回答，不展示源代码、测试窗口或文件路径。
- 若高亮或回答未完整出现，停止本次录制并重新从“录制前状态”开始，不在同一条视频中二次发送。
