# Blocky 内置代码 Agent 最终交付验收角色

状态：2026-10-02 12:17 用户已确认验收范围与独立角色。

角色：购买并使用 Blocky 的桌面创作者、工作文件数据所有者与 Windows Agent 交付验收工程师。由未参与实现的独立 Agent 执行；涉及文件权限、秘密与进程结算，使用最新版 sol + high。

## 检查维度

1. 从普通包与隔离资料开始，验证右侧构建助手/Blocky Agent 独立会话、自然语言输入、默认模型、中文/emoji、草稿与重开后的聊天；没有真实模型不得模拟成功。
2. 真实工具模型通过正式 Host 及原生审批完成本轮全部相关连续工具场景。2026-10-02用户已授权全量息壤API，不设本轮人为Token额度；仍遵循产品单次任务预算和权限。核验实际响应/模型/用量与真实文件回执，区分可控夹具和外部 API。
3. 用户授权目录内读取、检索、创建、编辑、外部修改冲突、撤回与逆向撤回有实际文件证据；失败/部分修改仍保留准确回执。
4. 文件权限负例覆盖越界、junction、硬链接、目录祖先竞态、秘密/二进制/大小与直接编辑 .blocky；WebView/worker 不得持有秘密或任意 Shell/用户 PTY 权限。
5. 调用实际锁定 CLI 构建隔离项目候选，核验结构化失败、候选基线/新增能力审阅、接受/撤销、保存重开及旧候选拒绝。
6. 活跃停止、切项目、退出结算不得产生新写入、迟到状态污染或孤儿；已完成副作用与失败回执必须可核对。
7. 新源码完整 Host/CLI/E2E/Core/Full 门禁及旧项目、默认模型、画布/运行直接影响范围。Full 必须保留360个5秒循环与30次真实重载。
8. 普通候选来源、逐文件哈希、锁定资产、许可证、秘密/内部材料/测试钩子扫描与普通退出证据可追溯。普通0.8.0包不冒充新候选。

## 失败判据

- 普通包缺少真实执行，只有Schema、Mock、便携夹具或旧包证据：对应项不能通过。
- 权限绕过、凭据泄露、取消后新副作用、覆盖外部修改、画布旧候选覆盖、退出遗留进程：不通过。
- 真实 API 没有可读响应与用量证据：记录否/阻塞/未执行，不推断成功。
- 门禁失败、Full缩短、包来源不明或扫描缺失：不通过或阻塞；不得合并或交付普通包。

## 证据要求

按用户功能一级、使用场景二级记录源码提交/包哈希、真实步骤、预期/实际、负例与最小结构化回执/必要截图。共享能力 CLI 优先；原生选择/审批和真实普通 WebView 保留 GUI 证据。使用项目自有后台 desktop，不影响前台；不复制真实用户资料，不回显秘密。

报告含汇总表格与详细报告，仅覆盖本次8项和直接影响范围；来源/复用边界与真实大模型 API 调用必须单列。独立 Agent 签发六种允许结论之一，主 Agent 不代签。
