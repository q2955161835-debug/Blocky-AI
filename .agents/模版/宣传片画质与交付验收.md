# 宣传片画质与交付验收

角色：从观众和影片交付方角度核对本轮超分优化的独立验收人员，未参与超分、导入、编辑或导出。用户已确认以下三项；等级L2。只验本轮v7及v6直接保持范围，不重验既有创意、不代签用户主观采纳，不扩大Blocky产品回归。

## Q01 · 画质优化 / 同镜头对照

按9份采用的超分源各取至少一个同时刻、同视域、同显示尺寸对照，检查Codex屏幕脸、Clawd轮廓、Blocky双凸点/表情、积木与放大镜关键边缘；选运动及Logo等代表范围加相邻帧核对。正常画面需有可见边缘改善，不凭像素尺寸变大判画质通过。严重新增光晕、角色变形、面部符号改变、错误纹理或相邻帧突变为失败；区分原源问题与本轮新增问题。证据给出源/时刻/画面与观察限制，不将抽帧称全片连续听感或零闪烁证明。

## Q02 · 原片保持 / 多源可编辑剪辑

比较v6与v7的11镜头采用时段、入点、播放速度、布局；9动画映射新源、两界面源保持。核对MG文字/时段/属性、音轨源/入点/增益/淡化、10视觉转场及3音频转场、2界面缩放参数精确保持，不因镜头ID变化误判参数变化。源嵌入音频数据包应保持；导出声轨与v6可比较数据包或PCM。保留新旧时间线并从真实工程读取，平面MP4不替代可编辑版本。实际成片定向查看开场气泡、两段界面文字、代表转场和片尾字标，缺字/误裁切/新空帧为失败；明确未实际听到时不能代签真人听感。

## Q03 · 成片交付 / 文件与出处

独立核对最终文件SHA/时长/尺寸/30fps/2010帧、音频规格和完整解码；绑定真实ChatCut时间线及导出ID。9输出源的尺度为2688×1536、24fps，帧数与原源保持，来源SHA与处理/导入映射可追溯；原v6及原源保留。无有效账号秘密、内部验收材料或开发规则出现在成品。不得将超分尺寸当作新原生生成、不扩大CLI/预设演示的真实能力边界。无法解码、帧数/关键参数不符、错误采用源或未完成导出即声明交付为失败。
