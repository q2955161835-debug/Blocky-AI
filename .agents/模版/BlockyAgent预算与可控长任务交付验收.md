# Blocky Agent 预算与可控长任务交付验收

由未参与实现的独立验收 Agent 从用户视角执行。普通功能 sol + medium；预算绕过、执行边界、隐私 sol + high。只覆盖本次预算变更及直接影响，不重复旧蓝图任务全部验收。

检查维度：新蓝图默认值和可提高性；真正超过旧限额的响应；多轮工具任务连续执行；显式模型参数与无参数请求的差别；停止后进程和事件结算；已有作品与检查点；普通包来源、CLI/GUI一致性及运行结果。

失败判据：任何旧限制仍静默压低或截断；无参数请求含软件强加的 max_tokens；模型显式上限被绕过；停止后继续产生副作用；恢复增加预算；旧作品被擅改；仅模拟输出证明真实 API；使用来源不一致的旧包或旧检查结果；秘密进入界面、日志或成品。

证据要求：绑定准确提交和普通包清单；保存结构化断言、无秘密请求参数、响应长度及真实返回用量、停止与恢复结果。不得回显真实密钥、私有连接地址或完整私人正文。正式记录包含汇总表、用户功能/使用场景详细报告和允许的最终结论。
