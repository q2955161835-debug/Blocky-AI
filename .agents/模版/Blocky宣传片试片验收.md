# Blocky 宣传片试片独立视听制作验收

角色：面向普通创作者的独立视听制作验收人员，从观众角度判断宣传片，不参与镜头、代码、音轨或封装实现。用户于 2026-10-12 确认以下三项验收范围。

## P01 · 观众理解创意

场景：第一次看到约一分钟宣传片。

- 开头出现重复受阻的反常现象；拉远揭示 C 形积木包住房间。
- 换一块积木之后空间和角色行动改变，因果顺序可辨。
- 核心信息为“像搭积木一样改造自己的 AI”，没有功能清单或无关蓝图介绍。
- 失败判据：没有核心揭示、因果颠倒、长时间无意义空镜或片尾没有品牌与核心信息。
- 证据：最终 MP4 时间点及代表帧；节奏判断说明抽样方式，不把静态图片检查称为完整实时观看。

## P02 · 观看视觉连续性

场景：从角色近景到揭示、换块、展开、编辑及落版。

- 角色保持蓝色双凸点积木及品牌表情特征，模型镜头与 MiniMax 片段边界无明显身份突变。
- 墙壁展开和角色移动具有可读的空间关系；字幕、主体和实际编辑目标可读。
- 失败判据：角色持续明显穿模/悬浮、主要对象意外被裁掉、明显空帧/闪黑、转场打断理解。
- 镜头中对象有意移出画面与主要信息不可读要区分，具体记录时间点。
- 证据：对镜头边界和运动高风险处定向抽帧；必要时加密同一短段，不扩大到产品回归。

## P03 · 播放与素材来源

场景：用户打开交付 MP4 及预览文件。

- 成片为约一分钟 16:9 MP4，视频/音频流正常，全文件无解码错误。
- MP4 内不含开发规则、验收报告、聊天或账号隐私；仅抽样可见文字和提交源清单的有限检查，不声称全面渗透审计。
- 实际积木编辑来源和动作有证据；网页预设输出不作为真实模型或桌面运行。
- 编辑后须同时核对实际可见字段、原始 fields 列表、来源声明及最终成片对应时间段一致；点击操作本身不算改动生效，菜单应已提交并关闭。此项由本轮首轮采集失败补强。
- MiniMax 是否采用、采用时间段、唯一 prompt_id、候选来源有准确记录；若生成失败或弃用如实记录。
- 证据：独立 ffprobe、全文件解码、SHA256、实际编辑记录和生成回执。
- 声音检验说明限制：波形/响度/解码不等于真人听感；不编造已听过音乐。
