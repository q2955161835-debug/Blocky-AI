# Blocky

Blocky 是一款面向普通人和学校教育的“积木式 AI 创作软件”。用户通过可拼接、可解释的能力积木创建 AI 伙伴，并在右侧运行对话栏与画布高亮中逐步看到它读取、思考、判断和行动。

![Blocky 当前图标概念](logo/logo.png)

当前阶段已形成完整积木与主流 Agent 兼容设计基线，但仍不包含应用代码或可运行原型。

三端技术尖峰所需的本机开发工具链已准备，并提供可复现的[开发环境检查入口](doc/开发/开发环境.md)；正式业务骨架仍须等待技术尖峰通过。

## 已确认方向

- 产品形态：安装式客户端，无 Web 版。
- 版本：教育版与专业版共用同一项目格式、积木语言和运行内核。
- 开发顺序：先完成不受订阅限制的完整产品，再按已验收能力切分教育基础、教育拓展和专业权益。
- 首发平台：Windows、Android、HarmonyOS；macOS 与 iOS 随后适配。
- 核心差异：不是节点连线式工作流，而是像 Scratch 一样能嵌套、能约束错误、能逐步执行的视觉语言。
- 桌面布局：左侧积木库、中间 Scratch 式画布、右侧 Agent 运行对话栏；产品不内置搭建辅助 Agent。
- 用户术语：单个能力称为“能力积木”，扩展分发单元称为“积木包”，共享入口称为“积木社区”。
- 内置模板：完整产品提供 OpenClaw 与 Hermes 的“原生兼容模板”；Blocky 连接或托管官方运行时，并将原生配置、能力和执行状态可逆地映射为通用积木，而不是另写一个近似版本。
- Agent 接入：提供 `blocky` CLI、官方 Skills 包和 Codex 等客户端的官方插件，使编程 Agent 能创建积木、搭建 Agent、转换 GitHub 项目和逆向现有 Agent，并与图形页进行可审查协作。
- 品牌素材：`logo/logo.png` 作为当前图标概念母图；正式上架前仍需制作各平台规范资源并完成小尺寸可读性检查。
