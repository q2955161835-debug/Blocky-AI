# Blocky

Blocky 是一款面向普通人和学校教育的“积木式 AI 创作软件”。用户通过可拼接、可解释的能力积木创建 AI 伙伴，并在执行台中逐步看到它读取、思考、判断和行动。

![Blocky 当前图标概念](logo/logo.png)

当前阶段只完成产品边界与技术架构，不包含应用代码或可运行原型。

## 已确认方向

- 产品形态：安装式客户端，无 Web 版。
- 版本：教育版与专业版共用同一项目格式、积木语言和运行内核。
- 首发平台：Windows、Android、HarmonyOS；macOS 与 iOS 随后适配。
- 核心差异：不是节点连线式工作流，而是像 Scratch 一样能嵌套、能约束错误、能逐步执行的视觉语言。
- 用户术语：单个能力称为“能力积木”，扩展分发单元称为“积木包”，共享入口称为“积木社区”。
- 品牌素材：`logo/logo.png` 作为当前图标概念母图；正式上架前仍需制作各平台规范资源并完成小尺寸可读性检查。

## 当前结论

首个可运行版本应先证明一个完整闭环：创建项目 → 拼积木 → 校验 → 手动运行 → 查看逐步执行 → 保存并在三端重新打开。账号、支付、公开社区、后台定时任务和大量连接器均不进入首个 MVP。
