## D 执行顺序

### D1：记忆条目、兼容与持久管理（A08）

- [x] 在旧 KV 基础上增加条目元数据与版本：来源、摘要、到期时间；旧记录可读，不隐式修改旧项目保存事实。Host 决定时间与用户/profile 根。
- [x] 建立按项目/会话限定的查询与删除接口，搜索索引与正文存储分层。读取/搜索时过滤过期、删除和撤权条目，索引不能绕过授权；写入使用版本冲突校验，失败保留旧有效状态。
- [x] Runtime、原生 IPC、CLI Schema/命令和管理界面共用协议。摘要来源区分原文摘取、实际模型和人工输入；不是把模型调用夹具称为真实摘要推理。
- [x] 覆盖同键冲突、跨用户/项目、过期、来源撤权、索引滞后、失败写入、实际进程重启、搜索/删除与保存重开；交独立 Agent 验收。

### D2：Skill 按需加载与工具约束（A09）

- [x] 先冻结 Skill 元数据/正文/附属资源协议，记录版本、摘要与工具引用。发现只读元数据，使用时才加载正文；不会把全部 Skill 放入模型上下文。
- [x] Host 管理实际安装根和文件字节，拒绝穿越、链接和越界资源。附带脚本不能隐式执行；只允许调用已声明、已登记且获准的工具。
- [x] 在共享 Runtime/CLI 和资源界面提供发现、加载、版本/权限与调用轨迹；使用合成或公开资料完成实际有用流程。
- [x] 验证正文恶意指令、越权工具、附属文件路径、未知版本、停止及进程回收，不将官方 work 路由冒充 Skill 安装。

### D3：委派、并行与汇总（A10）

- [x] 复用模块工具 fork，建立任务 ID、Agent 身份、输入/输出 Schema、父子关系、交接和结果来源协议。顺序与并行执行均为实际 Agent 子任务。
- [x] 子 Agent 获准能力为父范围内的显式子集；本机资源与审批仍由 Host 核验，共享总调用/Token/时间预算，不能给每个子任务重新发一份父预算。
- [x] 明确失败/取消/超时、顺序交接和并行汇总策略；等待已启动子任务结算后退出，防止停止后新动作。保持现有纯计算 parallel 校验。
- [x] 对实际模型子任务、权限收窄、跨项目资源、预算耗尽、递归、部分失败和停止做行为回归，GUI/CLI显示可核对的独立来源。

### D4：规则与实际模型评分（A11）

- [x] 建立有类型的输入字段、标签/分数、模型版本、阈值、后备和推理记录；不得把生成文本或规则评分标成已接入分类模型。
- [x] 优先核验是否能复用 C 已锁定跨编码器与 CPU 后端；只有实际模型/数据适用性经验证后才确定实现。它输出的 logit 不宣称是概率，英文适用范围须显示。
- [x] 完成“规则直接命中、实际模型推断、低可信/无模型后备”三个可重复作品场景，并处理非法输入、取消与共享预算。
- [x] 提供资源/积木/蓝图、结果轨迹和 CLI 对等入口，独立检查实际模型回执。JEPA 继续保持实验范围。

## E 执行顺序

### E1：持久触发与去重（A12）

- [x] Host 调度或已认证的外部事件启动已绑定的项目入口，复用 workflow task；定义时区、重复时点、重启、错过触发、暂停和退出规则。
- [x] 将触发版本、事件/发生 ID 与项目绑定持久化，CAS 去重后才启动；恢复不能重复完成的副作用，未知副作用沿用现有显式核验机制。
- [x] 限制外部来源、认证、内容大小和频率，不让事件正文自行授予资源/工具能力。凭据不进入项目或日志。
- [x] 实测定时与授权外部事件、重复投递、重启、暂停和退出，提供桌面任务入口、CLI 发现/Schema/状态/停止。

### E2：媒体引用与实际后端（A13）

- [x] 先建立 Host 媒体引用、容量/格式、SHA、profile 隔离、保留/删除和项目保存规则；前端只持有有界引用，不发送任意路径给模型。
- [x] 分别登记实际图片处理与音频转写能力及后端；无能力的文本模型明确拒绝。OCR 只能宣称文字识别，不能冒充通用图像理解。
- [x] 对新增音频后端锁定实际版本/工件/SHA/许可证，再接请求、进度、取消、结果及部署；不创建只能返回夹具的产品后端。
- [x] GUI 使用原生文件选择与预览，CLI 共用媒体管理；实测图片和音频、损坏/过大文件、撤权、删除、取消和后端不支持。

### E3：用户评估资产与版本报告（A14）

- [x] 数据集/版本/报告与运行状态分开存储；支持创建/导入、冻结内容和配置/模型版本绑定。冻结后编辑产生新版本，不改已完成报告来源。
- [x] 复用 Runtime 与持久 checkpoint 批量执行，记录逐例结果/稳定错误、取消和续跑；副作用未知不能自动重试。确定性指标可手算，模型评分/人工评分明确区分。
- [x] 提供两版作品比较、检索/引用/结构结果、耗时和已报告用量；未知用量不记零，报告脱敏，不无条件导出正文或凭据。
- [x] GUI 和 CLI 共用 Schema、状态、操作；将 C 的冻结语料作为可导入输入，而不是把固定开发脚本等同评估工作台。

## 整合与验收

每项完成适当行为/契约测试，先消除对应独立阶段发现，再进行后续共享整合。D–E 的接口探索和不重叠源码可以在云端进行；Windows Host、真实后端及原生证据必须使用相应环境，不能据 Linux 结果勾选最终通过。没有要求用户再次授权已确认范围。
