## 预期回答

```markdown
## 课程资料综合回答

### 1. 树叶为什么会在秋天变红

秋天气温降低、日照时间变短后，叶绿素逐渐分解，原本被绿色遮住的黄色和橙色色素开始显现。部分树种还会积累花青素，因此叶片可能呈现红色；不同树种和环境条件会使颜色表现不同。

- **关键过程：** 叶绿素分解、其他色素显现
- **课程依据：** [《秋天的叶子》§2]

### 2. 水循环为什么会形成降雨

太阳能使地表水蒸发成水蒸气。水蒸气上升并冷却后凝结成小水滴，小水滴聚集形成云；当水滴变得足够大、空气托不住时，就会以降雨等形式落回地面。

- **过程链：** 蒸发 → 凝结 → 降水
- **课程依据：** [《水循环》§1]

### 3. 资料完整性检查

- **树叶开始变红的具体摄氏温度：** 待核实
- **原因：** 当前课程资料没有提供可支持的具体答案。

> 回答范围：仅基于当前课程资料库。
```

## 录屏通过标准

- 总时长不超过 60 秒，且只有一次提示词输入和一次运行。
- 图片/文件/语音按钮及 Skill/插件菜单可见；输入文字、拆解/检索/重排/模型/护栏/引用/排版积木高亮、最终结构化回答三个关键画面均清晰可读。
- 回答下方出现绿色“真实 API · DeepSeek · deepseek-v4-flash · … Token”回报；没有该回报时本次录制作废。
- 录制结束前同时保留积木链和完整回答，不展示源代码、测试窗口或文件路径。
- 若高亮或回答未完整出现，停止本次录制并重新从“录制前状态”开始，不在同一条视频中二次发送。
