# 积木审阅产品价值

2026-10-03，用户要求将本定位加入PPT和商业计划书。本记录表达产品价值与后续场景，不新增产品实现或经营预测。

Blocky面向非专业用户，将Agent关键行为的代码审阅转为积木审阅。用户通过角色、任务、上下文、条件、记忆与工具积木理解设计，通过积木对应的运行轨迹检查实际过程，定位问题并修改作品。

审阅贯穿三个阶段：搭建时读懂结构和资料来源，执行前检查预期行为、工具与权限，运行后核对实际步骤与输出并重新检验。现有积木和运行轨迹提供审阅入口；非专业用户能否独立完成这些检查仍需用户验证。积木与轨迹不揭示模型内部推理，生成内容仍需判断和核查。

小学Agent创作教育是当前切入点：学生读懂、改造、自主搭建和解释作品，教师组织并记录帮助程度。后续可拓展到OPC（一人公司），让经营者审阅“Agent员工”的职责、资料、流程、工具与权限，减少只能看到最终答案的黑盒感。例如资料整理任务可在执行前逐块审阅，在运行后依据轨迹核对实际过程与结果。

OPC场景尚无客户、试用、效率或付费验证；进入前须另行核对经营者的审阅理解、权限判断、失败修订能力、支持成本和采购意愿。首批投入仍聚焦小学活动与教师复用，OPC不计入2027至2029三情景收入、合同量或资源预算。

本定位曾用于比赛 PPT 与商业计划书。赛事结束后，交付材料与专用验收记录已从当前工作树清理；当时的版本和文件哈希可从 Git 历史追溯。产品价值设计继续保留。
