# 个人开源、组织方案与独立算力

## 已确认决定

2026-10-03用户在材料整改中确认：个人版完全开源，组建社区生态；机构与K12付费方案包括组织后台配置，参照Blocks Builder AI的师生账户、课堂管理、进度分析、课程支持、优先支持，以及Tynker学校方案按学生数和学校需求组合报价。用户引用的调研对话明确Token订阅另算，参考WorkBuddy、Cursor、TRAE和OpenCode的算力收费机制。

小学Agent创作仍为入门版定位：读懂、改造、自主搭建、调试解释。组织付费不通过删减个人客户端创作能力实现。

| 组成 | 方向 | 核算与范围 |
|---|---|---|
| 个人客户端 | 完全开源、免费使用完整创作能力 | 发布源码、构建说明与许可证；开放发布状态需实际核验 |
| 社区生态 | 分享作品、蓝图、积木包、教学资源；鼓励修复与扩展贡献 | 贡献规范、版本、许可、权限与审阅；不能将计划当现有社区规模 |

| 教育与部署服务 | 课程支持、教师培训、配置、部署及优先支持 | 按明确交付范围报价，不把算力额度混入服务权益 |

## 当前事实与建设顺序

本段原计划路线已于2026-10-04调整：四类可自由改造起始蓝图按知识问答助手、工作助手、Coding 助手、Pi Agent 顺序正在实现，尚未验收；Pi Agent 必须由锁定真实上游核心并完成许可证、积木映射和运行循环验证。新建空白项目仍只有无资源、无问句的空 `main` 模块；旧16个软件起点和旧六品牌交付路线不再是当前产品目录。Codex 插件、内置构建助手与通用积木/工作流继续作为独立能力。后续再推进教育工作区、团队与部署、社区、macOS 和移动运行端等阶段；用户另提出结合 Agent 页面与积木结构，基于 Pake 或 Tauri 二次开发的一键生成 Agent App 方向，见[完整开发计划](../执行计划/2026-08-23-Blocky-竞品驱动完整开发计划.md)与[页面设计](Blocky-多画布应用界面与RPA设计.md)。个人版完全开源免费是商业和开放决定，不代表全部开发阶段已完成。

本轮只更新材料和产品方向，不实施后台或公开发布代码。2026-10-03 GitHub读回当前工程仓库仍为私有；根目录未发现Blocky个人版发布许可证。现有厂商/模型连接、项目文件、构建助手和轨迹等能力以既有产品验收为准，组织后台、社区平台、托管算力订阅与账单不能宣称已上线。

1. 开源发布准备：界定个人版源码和依赖、选择许可证、整理构建及贡献入口；在独立发布任务中审核实际开放清单。
2. 社区起点：提供可展开教学作品、蓝图与积木示例，形成许可和贡献规范，再根据真实贡献扩展分发能力。
3. 组织后台：围绕师生账户、班级任务、项目版本、学习记录、配置和权限形成原型，核对学校需求与部署范围。
4. 评价辅助：先检查明确的结构和任务规则，结合过程记录与教师复核；自动评分不等同模型内容正确或学习效果提升。
5. 独立算力：分别核算模型输入/输出/缓存、多轮与工具成本，建设额度、机构预算、用量和账单，再确定实际订阅价格。

以上五项在模板研发和后续产品建设过程中推进，真实教师、机构采用与付款在准备关口后分别采证；未预设已完成日期、用户数或收入。

## 材料与财务适用范围

用户确认24个月持续发展预算，并要求以真实数据校准Token成本。新[资金模型](../制作资料/2026-10-03-答辩与商业计划书/funding-24m/README.md)覆盖2026-11至2028-10，按学生、教师和专业创作者平台云活跃人月计费，研发内部算力另列。历史10个有回执短任务共82583Token，用官方DeepSeek峰价做敏感性重定价；专业创作者参考Claude Code公开开发者月成本，研发资源参考其活跃日成本，两类口径不叠加。任务频次、汇率、容量及排期仍为预算参数，短任务不能代表完整Agent成本。BYOK及本地用户排除，不当作真实采用或订阅售价。

基准前18个月研发现金支出196.413万元，外部用户算力在这段规划中为0；第19个月及以后容量须通过产品准备关口才启用，月份和人数不作为上线承诺。完整24个月条件预算现金支出573.239万元，最低追加需求866.443万元，按50万元步长取整覆盖目标900万元；专业创作者条件容量是主要算力驱动。900万元用于完整周期容量和储备覆盖，不能直接当作当前融资轮报价。未知收入与实际自有资金默认不抵减；若当月回收80%的用户算力成本，最低需求460.338万元、取整500万元，回收比例不是付费转化率或利润率。厂商30万元合作现金预留非报价；实际非退还费、预付额度与保证金分别更新，防止双算。原500万元基准结论只属于旧假设，当前以[独立验收](../验收/任务/验收-2026-10-03-研发主线与真实算力依据.md)绑定的新模型为准。

原每份均价1.8万元、80小时、模型预留1400元的试点服务模型只保留历史参考，不再用于完整产品资金主结论。该历史预算不是估值或整体盈利预测；实际收入、税务、部署维护、订阅周期、用量和厂商条款仍依合同与账单更新。

用户未确认引用聊天中建议的固定套餐金额、算力倍率或“算力一定为主收入”；本轮不将这些建议写成已定价格或业绩。
