## 1. 产品定义

> 像搭积木一样，创造、理解并使用自己的 AI 伙伴。

Blocky 是 Scratch 式的 Agent 视觉编程平台，不是“节点 + 连线 + JSON 面板”的流程工具，也不是只根据一句话生成不可见 Agent 的黑盒。积木的形状、嵌套、类型和连接规则共同表达程序；AI 可以辅助搭建，但 Project Manifest、各模块画布与编译后的 Module/Project IR 始终可检查、可重建。

核心承诺：

- 非技术用户可以通过足够细致、使用人话命名的积木组合能力。
- 能用代码构建的 Agent，原则上都能通过官方积木、组合积木、可视化自定义积木、代码自定义积木与受控原生保留机制表达。
- Agent 数量、主从关系、集群和协作拓扑由用户拼接结果决定，不设置语言层的人为上限。
- Agent 不是唯一架构根；RPA、状态机、规则、行为树、事件驱动、传统工作流、数据处理和混合 AI 系统复用同一模块、权限、运行与可观察协议。
- 先完成并验收完整产品，再切分教育基础、教育拓展和专业版权益，不维护多套不兼容内核。

Blocky 不提供浏览器 Web 入口；本地应用可以使用系统 WebView 渲染安装包内资源。用户明确要求为 Agent/自动化创建应用界面后，桌面端可在隔离浏览器标签中预览该项目的 Web 前端，但这不是 Blocky Web 版，也不会默认创建页面。

## 2. 目标用户

### 教育场景

- 12 岁以上学生、中职/高校入门课程和教师。
- 从教程、模板或空白画布理解 Agent 的输入、模型、工具、记忆、判断、权限和输出。
- 学校或教育机构可通过合作激活获得对应版本与管理方案。

### 专业场景

- 个人创作者、AI 重度用户、运营人员、开发者和需要精确控制 Agent 的小团队。
- 使用完整工具、代码自定义积木、原生 Agent 模板、CLI、Skills、插件与高级调试构建实际工作 Agent。
- 企业可通过咨询获得组织、激活与付费方案。

教育版与专业版可在同一应用内切换和预览，作品格式不因版本变化而分叉。

## 3. 平台职责

| 平台 | 产品职责 | 积木创作 | Agent 运行 |
|---|---|---|---|
| Windows | 首发完整桌面应用 | 完整 | 本机、桌面运行端或服务器 |
| macOS | 后续同级完整桌面应用 | 完整 | 本机、桌面运行端或服务器 |
| Android | 后续 Agent 使用器 | 不提供 | 能力协商后本机或远程 |
| HarmonyOS | 后续 Agent 使用器 | 不提供 | 能力协商后本机或远程 |
| iOS | 后续 Agent 使用器 | 不提供 | 能力协商后本机或远程 |

移动端只呈现由 Agent 交互入口生成的输入与运行界面。轻量、可移植且设备能力满足的 Agent 可以本地运行；需要桌面终端、文件、浏览器自动化、插件或特定原生运行时的 Agent 连接用户选择的 Windows、macOS 或服务器。执行位置、数据外发和费用影响必须对用户可见。

## 4. 桌面核心界面

整体布局参考“小猫快跑”式 Scratch 学习体验：

- 左侧：分类积木库、搜索、自定义积木和模板。
- 中间：带画布/浏览器项目标签的工作区。一个项目可打开多个 Agent、自动化或通用模块画布并跨画布稳定引用；浏览器标签只预览用户明确创建的应用界面。
- 右侧：两个明确分离的标签页——`搭建助手` 与 `运行 Agent`。
- 底部：可折叠的`问题 / 运行日志 / 终端 / 输出`面板。运行日志是 RuntimeEvent 的可读投影，完整调试进入运行轨迹；用户终端与 Agent 进程工具隔离。
- Windows 窗口：点击最小化默认进入通知区域并可恢复；最小化、关闭、退出和后台运行是不同动作。

### 搭建助手

Blocky 内置品牌化的“Blocky 构建助手”，模型来源可配置。产品边界是 Blocky 自有 BuilderAdapter、Build Spec、语义补丁、校验和授权协议；Pi SDK 是首选内部引擎候选，外部 Pi、Codex 或 OpenCode 客户端仍只是可选接入方。

- 默认审阅模式显示幽灵积木或差异，用户决定接受范围。
- 可切换直接搭建模式；每轮修改自动建立检查点并支持整轮撤销。
- 两种模式都不能绕过外部副作用、权限或原生写回确认。

Pi、Codex、OpenCode 等可以作为用户另行配置的外部搭建引擎。

### 运行 Agent

右侧运行输入栏是用户所搭建 Agent 的通用入口，不是固定功能的产品聊天框：

- 没有聊天交互入口积木时，`运行 Agent` 标签禁用。
- 多个入口可以切换和自定义名称，默认依次为 `输入 1`、`输入 2`。
- 文本、图片、文件、语音、Skill 与插件动作分别由入口中的能力积木解锁。
- 入口积木内部不放文本框或发送按钮；手工测试和真实聊天都使用右侧输入栏。

## 5. 积木语言

Blocky 给重要 Agent 语义独立的视觉身份，同时复用少量连接规则。一级语义形态包括：

1. Agent。
2. 交互入口。
3. 模型。
4. Prompt、指令与上下文。
5. Tool。
6. 记忆与知识。
7. Skill、插件与扩展。
8. 多 Agent 协作。
9. 护栏与权限。

Tool 从通用定义积木中分离为一等容器，同时生成：

- Tool Reference：附加给 Agent 进行自主选择。
- 显式调用积木：程序在确定位置主动调用。
- 结果与错误访问积木：读取结构化结果、流式进度和失败。

连接语法只保留事件帽、命令、类型值、条件、容器和引用等少量几何规则。简单视图面向非技术用户；展开高级栏后可以查看或编辑 JSON、类名、底层 API 和原生字段。

### 自定义与不可约代码

- **可视化自定义积木**：用现有积木封装，可展开查看内部结构。
- **代码自定义积木**：使用带类型、错误、权限、沙箱、预算与运行目标声明的局部代码。
- 两者都能自定义名称、外观、槽位、默认值、版本、许可证和社区信息。
- 代码积木不能隐藏 Agent 拓扑、工具契约、交互入口或宿主权限。

## 6. 模板、社区与原生兼容

模板是一组可保存、复用和继续修改的积木。用户可以从任意模板增删积木，创意与 Agent 拓扑不受模板限制。

Blocky 社区允许上传、下载、收藏、版本化和改造：

- 项目模板与片段。
- 可视化自定义积木。
- 代码自定义积木和扩展包。
- 兼容清单允许的原生 Agent 投影包。

可执行内容须经过来源、签名、许可证、依赖、权限、沙箱、资源预算和撤销检查；“可下载”不等于“安全”或“官方推荐”。

完整产品首批包含六个官方原生兼容模板：

- OpenClaw。
- Hermes。
- Pi：默认仅聊天入口、Agent、模型和 `read`、`write`、`edit`、`bash` 四个工具，保持极简。
- Codex：覆盖仓库级 AGENTS.md、Skills、MCP、沙箱、审批、工具、子 Agent 和结构化会话事件。
- OpenCode：覆盖主/子 Agent、工具权限、MCP、自定义工具、Skills、Plugins、会话与上下文。
- DeepSeek Harness：把 Profile、Bundle、Cordis 插件树、Agent 循环、工具、审批、沙箱和会话事件投影为通用积木；默认可使用 DeepSeek 模型，但不把模型提供商与 Harness 运行时绑定为同一语义。

模板由固定并验证的上游运行时、版本化适配器和可逆积木投影组成。用户修改后只有继续通过对应兼容矩阵，才能标注与该上游兼容。

## 7. CLI、官方 Skills 与插件

`blocky` CLI 与桌面图形页共享积木目录、编译器、IR、交互清单、权限和运行事件。它允许通用 Agent 在任意本地项目目录中读取、规划、生成、差异、校验、模拟并在得到授权后应用项目修改。

首批官方 Skills：

- `$build-blocky-agents`：搭建和修改 Agent。
- `$create-blocky-blocks`：创建可视化或代码自定义积木。
- `$convert-github-project-to-blocky`：把 GitHub 项目转换为积木。
- `$reverse-agent-to-blocky`：逆向现有 Agent，并生成证据映射、能力覆盖和原生保留报告。

Codex 等 Agent 的 Blocky 官方插件负责分发这些 Skills、发现 CLI 和连接图形页，不建立另一套隐藏语言。外部 Agent 不能直接编辑 Project Manifest、任一模块 Blockly Workspace、IR 或 `.blocky` 容器。

## 8. 账号、语言与商业基线

- 首发仅支持中国大陆；界面和内容架构准备简体中文、繁体中文、英语和日语，未来可扩展海外市场。
- 教育基础可在不登录时使用本地基础能力；正式账号使用邮箱验证码，游客作品可无损绑定。
- 一个个人账号最多同时激活 3 台设备。
- 账号可以绑定合作学校或企业，获得对应版本激活；教育机构和企业另有咨询付费方案。
- 教育拓展：单月 ¥128、连续包月 ¥98、年费 ¥980。
- 专业版：单月 ¥598、连续包月 ¥520、年费 ¥5,200；专业权益包含教育拓展权益。
- 从教育拓展升级专业版时，不退款；根据订单真实起止时间、实付金额和升级时真实剩余时长计算折扣。
- 离线权益只保留最后一次联网时的真实剩余时间：联网时剩 30 天可离线 30 天，联网时剩 7 天可离线 7 天，不额外增加固定宽限。
- 禁止未成年人独立购买，必须由成年人或监护人购买并确认条款；应用不设计未成年人专项退款入口，但依法保留人工处理能力。

具体支付、续费、折抵、机构授权、退款和账号风控须在商业实施前形成独立计费规格与 L3 验收；本阶段不接生产支付。

## 9. 数据与安全底线

- 项目、日志和 Build Spec 不保存真实密钥、Token、Cookie 或不必要的本机私有路径。
- 模型、文件、终端、网络、浏览器、插件和外部行动经过版本化 Host 契约和最小权限检查。
- 发送、删除、支付、发布、sudo、设备动作和原生配置写回等高风险操作采用当次、作用域明确、不可复用的授权。
- 搭建助手与作品 Agent 的会话、上下文、附件、工具结果和权限完全隔离。
- 移动端本地/远程执行位置和数据外发明确可见，不静默改变目标。
- AI 生成或逆向得到的积木必须通过与手工积木相同的类型、权限、循环、沙箱与兼容校验。

## 10. 开发与验收顺序

1. 完成并自审当前产品规格和积木清单。
2. 在 `try/` 完成 Windows Core 技术尖峰，不先搭正式业务骨架。
3. 建立共享语言、IR、Interaction Manifest、Tool 契约、项目格式和确定性模拟运行时。
4. 完成 Windows 多画布/浏览器标签、双右栏、底部面板、受控终端、日志系统、按需应用界面、通知区域、运行调试和本地项目闭环。
5. 完成自定义积木、扩展沙箱、社区与六套原生兼容适配器。
6. 完成内置搭建助手、CLI、四个官方 Skills 和官方插件。
7. 完整能力通过后再切分教育基础、教育拓展与专业权益，并实施账号和计费。
8. 后续交付 macOS 同级桌面应用，再分别验收 Android、HarmonyOS、iOS Agent 使用器。
