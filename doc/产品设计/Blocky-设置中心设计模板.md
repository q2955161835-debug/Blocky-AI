## 1. 目标

设置中心负责长期、可搜索、可迁移的产品偏好和运行配置，不承担所有对象的业务编辑。它必须让用户明确知道一个值来自应用、项目、资源还是当前积木，尤其不能把模型密钥、文件权限和网络权限藏在普通积木字段里。

设计原则：

1. 常用项易找，高级项可展开，不用“高级”掩盖危险操作。
2. 每个设置声明作用域、默认值、存储位置、敏感性、重启要求、迁移和重置行为。
3. 全局默认可以被项目覆盖，项目默认可以被积木覆盖；界面始终显示实际生效来源。
4. 安全值进入 Host 安全存储或 Git 忽略的 `.env`，项目和导出只保存不含秘密的引用。
5. 设置控件必须连接真实行为；尚未实现的功能不显示假开关。
6. 完整产品功能冻结前重新执行一次设置盘点，删除失效项、补齐缺失项并更新迁移测试。

## 2. 四层配置边界

| 层级 | 负责内容 | 示例 | 存储 |
|---|---|---|---|
| 应用设置 | 与所有项目共享的界面和默认偏好 | 语言、主题、快捷键、默认保存目录、更新通道 | 应用数据区 |
| 项目设置 | 影响当前 `.blocky` 项目的非秘密策略 | 默认入口、默认模型配置引用、运行预算、自动保存策略 | 项目清单或项目旁路元数据，须明确版本 |
| 资源配置 | 可被多个积木引用的能力实例 | Provider、模型、知识库、工具、Skill、MCP、护栏 | 资源注册表；秘密仅存引用 |
| 积木配置 | 当前积木对资源或行为的局部覆盖 | 温度、最大输出、检索数量、超时、错误策略 | Workspace JSON 中的受校验字段 |

不得把应用视图偏好写入 Agent 项目，也不得把真实 API Key 写入 Workspace、IR、Build Spec、蓝图、运行事件或日志。

## 3. 入口和布局

入口保持一致：

- 顶部“设置”菜单 → “打开设置”；
- 命令中心 → “设置：打开设置”；
- 左下角齿轮按钮；
- 积木诊断中的“去配置”直接打开设置中心或资源编辑器的准确字段；
- `Ctrl + ,` 作为默认快捷键，若与系统或 WebView 冲突则由命令注册表报告并允许改键。

设置中心采用单窗口双栏布局：左侧分类与搜索，右侧显示字段。顶部搜索同时匹配中文名称、英文技术名、说明、关联积木和命令。搜索结果显示所属分类和生效作用域，不把应用设置、项目设置和资源配置混在无来源列表中。

每个字段统一显示：

- 名称与简短说明；
- 当前值和默认值；
- 生效作用域：应用 / 项目 / 资源 / 积木；
- 来源：默认 / 用户设置 / 项目覆盖 / 积木覆盖 / 策略锁定；
- 是否需重启或重新运行；
- “恢复继承”或“恢复默认”；
- 风险、权限和数据去向（如适用）。

## 4. 第一版分类模板

### 4.1 常规

| 设置组 | 候选项目 |
|---|---|
| 启动 | 启动时打开欢迎页、恢复上次项目、检查未恢复草稿 |
| 窗口与后台 | 最小化目标、关闭保护、窗口状态恢复、用户已启动任务在隐藏时是否继续；Windows 默认最小化到通知区域 |
| 语言 | 界面语言、内容语言、术语显示；首发以简体中文为基线 |
| 文件 | 默认项目目录、最近项目数量、导入/导出默认位置 |
| 保存 | 自动保存开关、延迟、恢复副本数量、关闭前保护 |
| 更新 | 稳定/预览通道、自动检查、下载后提醒；正式签名前不显示假更新开关 |

### 4.2 外观与无障碍

| 设置组 | 候选项目 |
|---|---|
| 主题 | 深色、浅色、跟随系统、高对比度 |
| 文字 | UI 缩放、编辑器字号、轨迹字号 |
| 动效 | 正常、减少动态效果；关闭呼吸光晕但保留状态轮廓和文字 |
| 状态 | 激活/警告/错误的颜色预览、线宽和图标；只允许满足对比度的受控主题 |
| 辅助输入 | 键盘焦点增强、屏幕阅读提示、触控笔优化、长按阈值 |

### 4.3 编辑器与画布

| 设置组 | 候选项目 |
|---|---|
| 默认模式 | 入门视图 / 专业视图；选择模式为默认输入模式 |
| 选择 | 框选相交/完全包含规则；`Shift + 左键` 点击多选固定启用，不提供破坏习惯的关闭项 |
| 平移 | 鼠标中键拖动固定启用；Space + 左键作为临时平移；触控板手势 |
| 缩放 | 滚轮方向、缩放步长、最小/最大比例、以指针为中心 |
| 布局 | 网格、吸附、迷你地图、区域、自动整理和防重叠策略 |
| 积木 | 显示密度、蓝图折叠层级、分类提示、连接错误说明 |
| 项目标签 | 是否恢复上次打开标签、最近关闭数量、预览空闲回收；标签会话状态不得写入作品运行语义 |
| 多画布 | Project Map 展示密度、跨画布打开方式和返回导航；不得提供把 Project Map 变成第二套节点编辑器的开关 |

固定交互不得被普通主题或插件静默重写。扩展若需要新的输入手势，必须经过命令冲突检测和用户明确启用。

### 4.4 快捷键

快捷键页按“文件、编辑、画布、构建、运行、调试、视图、设置”分组，支持：

- 按命令或按键搜索；
- 录入新组合键；
- 显示冲突、系统保留和作用域冲突；
- 同一命令设置主/备用快捷键；
- 按命令、分类或全部恢复默认；
- 导入/导出不含秘密的快捷键配置；
- Windows `Ctrl` 与 macOS `Cmd` 的平台映射。

默认快捷键以完整开发计划 9.4 节为基线。任何改键仍调用同一 `CommandDefinition`，不创建第二条执行路径。

### 4.5 Blocky 构建助手

| 设置组 | 候选项目 |
|---|---|
| 工作方式 | 审阅后应用 / 带检查点直接搭建；高风险动作始终单独确认 |
| 模型 | 构建助手使用的 ModelProfile、回退配置、最大步骤和预算 |
| 补丁 | 幽灵积木预览、自动整理范围、拒绝补丁后的保留策略 |
| 官方 Skills | 四个官方 Skills 的版本、启用状态、来源、兼容 CLI 版本和校验结果 |
| 隐私 | 允许发送的项目范围、代码/文档摘要策略、脱敏预览 |

用户不能通过一个总开关授予构建助手任意文件系统、Shell、网络和外部账号权限。

### 4.6 模型与 Provider

Provider 配置作为资源管理器的一部分，也可从设置中心进入。每个 ModelProfile 至少包含：

| 字段 | 说明 | 敏感性 |
|---|---|---|
| 显示名称 | 用户可识别的配置名 | 非敏感 |
| Provider 类型 | OpenAI-compatible、厂商原生、本地服务等 | 非敏感 |
| Base URL | API 根地址；允许自定义兼容端点 | 可能敏感，日志和导出默认脱敏 |
| API Key 引用 | Host 安全存储或 `.env` 变量引用 | 敏感；不展示完整值 |
| 模型 ID | 手动输入或经授权发现 | 非敏感 |
| 能力 | 文本、图片、音频、工具调用、结构化输出、上下文长度 | 经连接测试或静态声明 |
| 请求 | 超时、重试、并发、代理、额外兼容头 | 额外请求头可能敏感 |
| 预算 | 单次 Token、费用和时间上限 | 非敏感 |

配置页提供“测试连接”，只报告连接、认证、模型发现、最小文本和工具能力类别，不把请求/响应正文写入持久日志。验收需要真实 API 时，Agent 主动请用户在此页面或本地 `.env` 配置；不得要求用户把密钥复制到聊天、README 或验收文档。

### 4.7 工具与权限

| 设置组 | 候选项目 |
|---|---|
| 文件 | 可访问根目录、只读/读写、符号链接/重解析点策略 |
| 终端 | 禁用/白名单任务/隔离 Shell、超时、输出上限、工作目录 |
| 网络 | 允许域、代理、重定向、下载上限、证书错误策略 |
| 浏览器 | 可用浏览器、登录资料隔离、下载和上传策略 |
| 应用界面预览 | 每项目独立存储分区、允许的远程测试域、空闲预览回收和下载目录；默认项目无应用界面 |
| 桌面自动化（RPA） | 浏览器语义/UI Automation 优先、图像/坐标回退警告、截图保留、录制隐私、短期授权和暂停热键 |
| 外部副作用 | 发送、发布、删除、支付、设备动作和原生写回的确认策略 |
| 授权记录 | 当前会话的短期授权、过期时间、撤销和脱敏审计 |

危险权限不能使用“全部永久允许”作为默认建议。项目模板和社区蓝图只能声明所需权限，不能自动授予权限。

| 设置组 | 候选项目 |

| 画布高亮 | 激活绿色、警告黄色、错误红色；光晕强度、持续时间、减少动效 |

运行高亮是瞬时状态；代码自定义的有效/警告/无效徽标是持久状态。设置预览必须同时展示两层，防止主题造成混淆。

## 5. 积木配置面板模板

双击可配置积木、右键“配置”或检查器中的配置按钮打开同一配置面板。面板按以下顺序显示：

1. 当前积木名称、来源、版本和状态；
2. 公开业务参数；
3. 引用资源及其健康状态；
4. 当前值的继承链；
5. 权限、网络、文件和外部副作用；
6. 错误处理、超时、重试和回退；
7. 代码/高级实现（仅适用时）；
8. 校验、测试连接、运行一次和恢复继承。

模型积木的快速配置可以选择已有 ModelProfile 或新建配置。新建时转入资源编辑器；保存后返回原积木并建立引用。API Key 字段只显示“未配置”或脱敏尾部，不提供复制完整密钥按钮。

## 6. 设置 Schema 最小契约

每个正式设置项至少声明：

```ts
type SettingDefinition = {
  id: string;
  title: string;
  description: string;
  category: string;
  scope: "app" | "project" | "resource" | "block";
  valueType: "boolean" | "number" | "string" | "enum" | "secretRef" | "command";
  defaultValue?: unknown;
  sensitive: boolean;
  requiresRestart: boolean;
  dependsOn?: string[];
  conflictsWith?: string[];
  migrationVersion: number;
  validate(value: unknown): SettingDiagnostic[];
};
```

实现时 Schema 是设置 UI、默认值、搜索、导入导出、迁移和测试的唯一事实来源。安全存储实现只接受 `secretRef`，不允许普通字符串字段偷偷保存密钥。

### 6.1 首批窗口、预览与 RPA 字段候选

这些字段是阶段 0 的 Schema 候选，只有对应行为实现并通过测试后才进入正式设置 UI：

| ID | 作用域 | Windows 候选默认 | 约束 |
|---|---|---|---|
| `window.minimizeTarget` | 应用 | `notification-area` | 可选 `taskbar`；不改变运行状态 |
| `window.closeBehavior` | 应用 | `ask-when-dirty-or-running` | 关闭与最小化、退出分离；运行/未保存时保护 |
| `background.continueUserRunsWhenHidden` | 应用/项目 | `true` | 只影响用户已经启动且获权的运行，不得自动启动任务 |
| `window.restoreState` | 应用 | `true` | 显示器移除或 DPI 变化后仍须恢复到可见区域 |
| `workspace.restoreTabs` | 应用 | `true` | 仅保存用户会话，不写入 Project IR |
| `browser.previewIsolation` | 应用 | `per-project` | 安全固定项；不得改成跨项目共享 Cookie/存储 |
| `browser.stopIdlePreview` | 应用/项目 | `true` | 关闭最后一个浏览器标签后按空闲策略回收预览服务 |
| `rpa.selectorPreference` | 应用/项目 | `semantic-uia-first` | 绝对坐标始终是带警告的最后回退，不能设为无警告默认 |
| `rpa.captureRetention` | 应用/项目 | `minimal` | 截图按需、脱敏、限额和定期清理 |
| `rpa.recorderPrivacy` | 应用 | `protect-sensitive-inputs` | 密码、Token、验证码和隐私字段不记录明文/截图 |
| `bottomPanel.restoreState` | 应用 | `true` | 只保存本机布局会话，不写入项目语义 |
| `bottomPanel.openOnError` | 应用 | `true` | 可关闭自动打开，但状态栏仍显示问题 |
| `runLog.followLatest` | 应用 | `true` | 用户手动上滚后暂停跟随；运行日志仍由 RuntimeEvent 投影 |
| `terminal.defaultProfile` | 应用 | 系统发现值 | 保存 Profile ID，不修改系统默认 Shell |
| `terminal.confirmOnActiveClose` | 应用 | `true` | 活动进程必须明确终止；项目和 Agent 无权覆盖 |
| `terminal.outputBudgetBytes` | 应用/项目 | 有界值 | 由产品上限约束；超限显示截断事件，不阻塞进程 |
| `logs.level` | 应用 | `info` | 正式构建默认不持久化 `trace`；不影响审计底线 |
| `logs.retentionDays` | 应用 | 有界值 | 诊断与审计分别治理，不随项目导出 |
| `logs.maxDiskBytes` | 应用 | 有界值 | 超限按类别与时间回收并保留摘要 |

`browser.previewIsolation` 和 `rpa.recorderPrivacy` 属于安全底线，设置页只解释当前策略，不提供削弱保护的普通开关。应用界面是否存在是项目对象事实，不是全局“自动创建页面”设置。用户终端与 Agent 进程工具的隔离、日志先脱敏后分发同样是固定安全边界，不提供弱化开关。

## 7. 错误与恢复

- 设置值无效：保留上一个有效值，显示字段级原因，不让整个设置页崩溃。
- 设置文件损坏：隔离损坏副本并恢复默认；项目内容不受影响。
- Provider 测试失败：区分网络、认证、模型不存在、协议不兼容和能力不足，不记录响应正文。
- 扩展引入快捷键冲突：扩展命令保持未绑定并提示用户选择，不覆盖现有键位。
- 项目引用缺少本机秘密：项目可打开和查看，但相关积木显示“需要配置”，不能把缺失秘密当成项目损坏。
- 设置迁移失败：阻止使用受影响设置，提供恢复默认或导出脱敏诊断，不静默丢弃用户值。

## 8. 分阶段实施位置

| 阶段 | 设置工作 |
|---|---|
| 阶段 0 | 已冻结 SettingDefinition、ResourceDefinition、作用域、秘密边界及底部面板/终端/日志字段语义；实现未开始 |

## 9. 最终设置复核任务

设置中心当前是实施模板，不是冻结到发布的最终字段表。正式 Windows 产品功能完成并进入发布候选前，必须创建独立任务：

1. 从真实命令、资源、积木、Host、适配器和运行时生成能力清单；
2. 逐项对照设置 Schema，删除无消费者的设置和重复入口；
3. 为缺失但用户必须控制的真实能力补充设置；
4. 重测默认值、作用域继承、重置、导入导出、迁移、无障碍和秘密隔离；
5. 使用普通用户、教师和专业开发者分别完成设置查找任务；
6. 更新本文件、帮助文档、模块验收和最终发布记录。

该复核完成前，不得宣称设置中心已覆盖最终产品全部功能。
