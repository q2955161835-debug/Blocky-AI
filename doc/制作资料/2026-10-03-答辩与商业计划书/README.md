# 云端材料制作输入

这是内部制作资料。先读[小学Agent入门教育重写计划](../../执行计划/2026-10-03-Blocky小学Agent入门教育材料重写与云端交接.md)。旧稿以单个Agent查询和生成文件为主，已经被用户否定；以下源文案仅用于提取结构与事实，不直接生成交付稿。

| 文件 | 用途与限制 |
| --- | --- |
| `ppt-reference-v6.mjs` | 旧PPT原生文字、图表和图像制作参考；含本机路径，云端先适配依赖及路径，并整体重写内容 |
| `prepare_ppt_metadata.py` | 原生PPT图片裁切和文档元数据处理参考；需按新稿标题、输入和图片顺序复核 |
| `speaker-notes-reference-v6.json` | 旧讲稿；可核对事实，开场、主体和收尾必须按教育主线重写 |
| `business-plan-reference-v1.1.json` | 旧商业计划书结构和事实输入；市场、产品价值、课程与客户论证需重写 |
| `build_business_plan_docx.py` | 使用项目技能Word模板构建文档的参数化脚本；字体、字段和页面仍需渲染检查 |
| `finalize_word_docx.py` | Word保存后规范化格式与元数据的参考；不得以机器检查代替全页阅读 |
| `finance-summary.json` | 已有三情景汇总，金额单位按字段使用；全部是2027–2029假设 |
| `finance-model-validation.json` | 作者财务检查来源与快照；独立重算另见验收证据，不等同商业计划书通过 |

商业计划书模板在`.agents/skills/build-client-business-plans/`内，具体路径从该技能入口确认。公开产品截图与合成资料在`doc/验收/任务/答辩与商业计划书证据/产品演示/`；插画与完整提示词在`doc/设计素材/2026-10-03-答辩/`。它们均已纳入Git，不需要本机try目录或私人账号。

当前PPT/PDF、DOCX/PDF和XLSX位于`doc/交付/2026-10-03-答辩与商业计划书/`。该目录仅为待重构参考快照：PPT不通过，BP未执行，只有财务数值有局部通过证据。新稿全部通过后再清理交付目录和本制作目录中过时文案。

这些脚本保留为有限任务输入，不是Blocky产品代码或通用跨平台制作工具。云端使用自身已配置的Node/Python及文档工具，不照搬本机C盘运行时。没有运行云端适配、产物重建或新稿验收。
