# Blocky 现代桌面工作区实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 Windows Core 尖峰改造成已批准的第四版现代桌面工作区，同时使用真实 Blockly 积木、消除持久顶层重叠，并保证侧栏收纳不改变画布变换。

**Architecture:** 保留唯一可编辑 Blockly workspace 以及既有 workspace JSON → IR → manifest/runtime 数据流。React 桌面壳只负责标题栏、固定侧栏和画布内控制；积木目录、真实预览、放置服务、运行事件视觉和 Tauri 窗口桥分别形成窄模块。所有自动布局只读取真实 Blockly 渲染边界，侧栏收纳路径只能执行容器 resize。

**Tech Stack:** React 19.2.8、TypeScript 7.0.2、Blockly 13.2.1、Tauri API 2.11.1、Tauri CLI 2.11.4、Vitest 4.1.10、Testing Library、WebdriverIO、Microsoft Fluent UI System Icons React 2.0.316。

## Global Constraints

- 实现目标只限 `try/windows-core-spike/`，不得修改 Blocky IR、项目格式、HostBridge 保存契约或运行时语义。
- 设计示意图中的矩形不能代替积木；积木列表和主画布必须使用现有 Blockly 注册表的真实 SVG 形状、字段、连接结构、尺寸和颜色。
- 左右侧栏收纳只能增加可见画布范围；不得调用适配、居中、自动排列或改变 workspace scale/translation/积木坐标。
- 只有用户主动点击右下角“适配画布”才能执行 `zoomToFit` 或居中。
- 自动插入、拖放结束、100 块夹具和旧重叠数据不得留下持久顶层重叠；合法连接、嵌套和吸附不视为重叠。
- 常见操作使用 `@fluentui/react-icons` 实际图标；中文只用于菜单、可见状态、`aria-label` 和悬停提示。
- 普通构建必须继续本地加载资源，不得加入远程代码、WDIO 钩子或额外网络权限。
- 依赖只安装在 `try/windows-core-spike/` 项目环境并锁定精确版本。
- 每个任务先运行聚焦 RED，再写最小实现并运行 GREEN；任务完成后独立提交。
