# 蓝图与聊天会话交互实施计划

**目标：** 左下整块统一称“蓝图”并可折叠、调整高度；右侧输入向上增长至 40%，输出跟随与阅读位置保持；两个助手有同一行入口和可找回的独立历史会话。

**架构：** 复用 ResizeHandle，实现独立 BlueprintDock、ChatComposer 和滚动跟随 Hook。会话索引按项目及助手分别保存，正文按独立会话文件保存，既有 coding-chat/v1 作为迁移来源与当前会话兼容投影；历史仅保存文本，不恢复 Host 文件授权、候选或执行权限。

**技术栈：** React / TypeScript、既有 UserStore 原子写入、Rust Host；不新增依赖。

**依据：** 本聊天已确认的布局、40% 上限及会话补充验收；“蓝图”为用户指定总称。沿用普通独立功能验收角色，不新增复杂模板。

- [ ] 布局：Library.tsx 整块收纳；新增 BlueprintDock.tsx、ChatComposer.tsx、useChatFollow.ts 及对应组件测试。输入增长、手动上边界拖动、空闲保持、手动阅读不跳底。
- [ ] 保存：新增 chatHistory.ts、useChatHistory.ts；接入 useCodingChat.ts、useCodingAgent.ts 和 useStudio.ts。覆盖旧格式迁移、重开、助手/项目隔离、保存失败不覆盖历史；运行中禁用切换。保留当前 CLI 格式。
- [ ] 入口：StudioSidebar.tsx 同行提供新会话、历史搜索下拉、当前助手设置；BuilderPanel/RunPanel 复用输入布局及滚动 Hook。历史无可执行旧候选。
- [ ] 验证：相关组件、类型及 Host 存储测试，构建新的普通桌面包；独立 Agent 验收本轮涉及范围。旧三个桌面场景窗口及痕迹保留。
- [ ] 收尾：归档本计划、更新正式验收和进展记录，按冻结来源核对普通包；团队 main 合并、分支清理及推送仍需单独授权。
