## 3. 架构选择

采用“扩展现有共享领域与 Host”的方案：模型、工具、知识、状态与事件契约由 Blocky 持有，桌面、CLI、构建助手共享服务。外部框架作为适配参考，不成为另一套项目编辑事实。

另两条路径是外部 Agent 框架整包托管作品，以及重写运行内核。前者需要额外解决积木语义、保存恢复和权限映射，后者会扩大已验收核心的迁移范围；本轮选择现有架构上的模块化补全。

### 3.1 模型资源与 Host 网关

- 模型声明生成、工具调用、结构化输出、嵌入、重排、分类/评分、图像或音频能力。配置界面只显示当前适配器真实支持的能力。
- 保留 DeepSeek、息壤与本地 E5；增加自定义兼容服务、Ollama 本地服务及可校验的本地模型工件。端点、凭据和敏感请求头由 Host 保管，WebView 与项目只存引用。
- 本地生成同时支持连接已有服务和由 Blocky 管理的本地推理进程。模型单独安装、校验和删除，显示实际磁盘与运行状态；加载、显存/内存预算、取消和退出回收有统一控制，不把机器上未安装的服务当作已完成交付。
- 自定义公网连接使用明确登记的 HTTPS 目标；本地服务单独登记 loopback 地址。重定向、解析后地址、目标变更和请求预算由 Host 检查，不能把现有固定端点检查简单删除。
- 模型请求与响应升级为有版本的文本/工具调用/工具回执/媒体引用协议；真实 Token 用量有值才记录，供应商未提供时明确 unavailable，不能伪造零值。
- 嵌入索引签名包含模型工件或服务标识、维度、归一化和分段版本；换模型后重建新索引并原子切换，原索引可回退。

### 3.2 作品 Agent、工具与控制流

- 实现已有设计的工具选择循环、动作选择、停止条件、有界循环、逐项处理及失败分支。模型提出工具调用，Runtime 校验 Schema，Host 执行获准能力，结果回到同一会话。
- 复用运行预算、取消、事件、审批、任务与检查点。循环和子 Agent 共享总预算，重复副作用通过实际执行状态处理；回放仅展示记录。
- 工具优先接入项目模块、既有文本分析、受控 HTTP/搜索、既有 RPA 和 MCP。所有入口返回可定位的错误和结构化回执。
- MCP 先支持 stdio 与 Streamable HTTP 的协商、工具发现/调用和资源读取；外部服务不能取得用户 PTY、任意 Host 文件或隐式模型调用权。
- 构建助手调用同一目录、Schema 和领域服务，能解释缺失配置并搭出新增流程。

### 3.3 知识处理

- 将已有来源、同步、嵌入、索引与删除领域能力开放为可组合积木，并提供可展开的摄取蓝图。
- 支持 PDF、DOCX、XLSX、CSV、现有文本/网页/源码；图片与扫描 PDF 提供本地 OCR。保留页码、段落、工作表/单元格或图像区域等定位信息。
- PDF 采用独立解析/渲染适配器，优先评估 PDF.js；Office/表格使用有大小、解压、嵌套及执行时间限制的解析器。OCR 为独立可检查的模型/运行时资源，缺失时明确安装或修复路径。
- 分段预览、嵌入/重排选择、同步进度、失败恢复、索引状态与引用查看使用相同领域结果。
- 增加真实模型重排、问题改写与相关性判断蓝图；已有规则评分保留独立名称。证据不足时可澄清、重新检索或结束，均受预算约束。

### 3.4 记忆、协作、Skill 与决策

- 在现有会话/项目记忆基础上增加搜索、摘要、有效期、来源和冲突策略；索引与记忆存储分层，跨项目默认隔离。
- 多 Agent 使用有类型的任务、输入/输出和交接记录；明确顺序、并行、汇总、失败/取消与权限继承。保持原有纯计算并行积木的语义。
- Skill 以可发现的元数据、按需正文和受控工具引用加载。引用文件路径受资源根限制；脚本通过已声明工具能力执行，不隐式执行附带代码。
- 学习式决策采用可验证的分类/评分模型资源，记录输入字段、输出标签/分数、版本、阈值和后备路径。以真实模型推理演示规则与模型协作；分数是否具有概率意义由模型元数据说明。

### 3.5 事件、多模态与评估

- 增加本机定时和已授权外部事件触发；定义时区、错过触发、重复投递、停止/重启与去重语义，复用持久工作流。
- 提供图像输入与音频转写的模型能力接口，媒体由 Host 管理引用与容量，项目保存规则明确。首批以实际可用的已登记后端完成演示。
- 用户可建立测试集、运行批量评估、查看检索命中/引用、结构化结果正确性、耗时和用量，并比较两版作品。测试资产和报告与运行数据分开管理。
- 所有新共享功能同步提供命令发现、Schema、结构化状态、稳定错误与恢复入口；GUI 保留原生选择、预览和可视化操作。
