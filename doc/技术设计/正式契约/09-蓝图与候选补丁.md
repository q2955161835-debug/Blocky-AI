# 阶段 1 蓝图与候选补丁消费边界

本增补对应已确认 D 与 CLI S1-12，不改变阶段 0 的 21 个冻结 Schema。消费者是 `block-catalog`、`builder-protocol`、`conversion-core`、桌面编辑器与 CLI；正反输入由这些包及 `tests/cli/commands.test.ts` 的行为测试构造。

## 个人蓝图

新增 `blocky.blueprint/v1alpha1`：必需 `blueprintId/displayName/version/catalogVersion/source/roots/resources/modules/digest`。`version` 为 1；`source` 仅含个人来源与项目/画布 ID。`roots` 保存顶层 Workspace 积木及相对坐标，`collapsed` 是可选折叠状态，缺省展开。每次插入重新生成所有积木 ID。

`resources` 与 `modules` 是必需外部依赖的公开插槽，保存种类、稳定引用及模块接口签名，不保存资源值或凭据。插入必须显式绑定；源项目同名 ID 不作为隐式授权。当前不支持把导出入口随选区复制，遇到 `core.tool.entry` 阻止保存。展开与折叠保留原子积木，非另一套执行语言。

输入严格拒绝未知字段/目录项/插槽、不合法 ID、重复 ID、越界、疑似凭据文本与被篡改摘要。蓝图限制 100 顶层栈/100 插槽，遍历 10000 节点及深度 60；CLI 工件限制 2 MiB，本机蓝图库最多 100 项/2 MiB。旧读取器遇到新增 Schema 拒绝，不静默降级。存储为本机个人库或显式导出的独立 JSON，不自动写入项目。

## 变更审阅与事务

消费冻结 `blocky.patch/v1alpha1` 的当前支持子集：`block.add`、`block.update`、`block.move`、`block.remove`。其他操作拒绝；增加/移动/移除针对顶层栈，字段更新走共享目录配置函数。上限 500 操作。`baseDigest` 与 `catalogVersion` 必需，摘要包含完整当前项目事实。

预览重新编译候选，显示每项 before/after 结构；重新计算权限增量并与声明逐项对照，不信任传入诊断。接受前检查用户独立批准的新增权限，在 ProjectController 单一事务内再次检查当前事实；过期、失败、拒绝均不产生半次编辑，成功可整体撤销。磁盘写入另走现有 Rust 项目校验及原子保存，CLI 始终写新目标，不覆盖原项目。当前共享领域接受不是独立的远程 Host 补丁授权端点，不能据此宣称开放任意 Agent 写盘权限。
