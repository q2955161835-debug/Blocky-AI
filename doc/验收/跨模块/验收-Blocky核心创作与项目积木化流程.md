## 详细报告

## U01. 首次启动并从蓝图创建资料问答伙伴

前置条件：干净用户配置；正式阶段 1 Demo 构建；不提供模型密钥。

用户操作：

1. 安装并启动 Blocky Studio。
2. 在空工作区选择“资料问答伙伴”。
3. 查看蓝图结构和三个首要可改位置。
4. 使用默认内容完成第一次运行。

预期结果：

- 用户无需理解 Provider、Embedding、IR 或 Harness 即可进入可运行画布。
- 画布是真实可编辑积木，不是说明卡、图片或录屏。
- 不在界面、项目文件或运行数据中加入仅供 Demo 使用的徽标、横幅、水印或持久字段。
- 默认流程使用正式 Provider/知识接口注入的本地确定性实现，后续可直接替换。

证据：首次启动录屏；完成耗时；误点/返回次数；项目摘要；运行轨迹截图。

检查方法：人工从全新配置执行；阶段 1 E2E 自动覆盖创建、运行和首屏可操作性。

## U02. 修改角色、知识和回答方式并理解错误

前置条件：U01 项目已创建。

用户操作：

1. 修改角色名称和回答语气。
2. 替换一个知识来源。
3. 故意清空必填配置并尝试运行。
4. 按错误提示恢复配置。

预期结果：

- 入门视图只暴露完成任务所需插槽；专业视图可看到同一底层积木。
- 缺失配置显示可执行的中文诊断，并能直接打开对应配置项。
- 修复后不需要重建项目；入门/专业切换不改变运行语义。

证据：修改前后 Workspace 摘要、诊断代码、恢复后的运行结果。

检查方法：人工操作；组件/E2E 覆盖必填配置和视图无损切换。

## U03. 运行、观察积木状态并从轨迹定位问题

前置条件：资料问答伙伴可运行；准备正常、警告和错误三个输入。

用户操作：

1. 运行正常问题并观察画布。
2. 触发低置信度或预算警告。
3. 触发知识缺失或 Provider 错误。
4. 在运行轨迹点击事件跳回来源积木。

预期结果：

- 当前激活积木外轮廓加粗并绿色亮起；警告黄色；错误红色。
- 颜色同时配有图标和文字，减少动态效果时仍能识别。
- 运行状态不改变积木尺寸，不与代码自定义状态徽标混淆。
- 轨迹显示脱敏输入、输出、来源和稳定错误，能定位真实积木。

证据：三种状态截图/视频、RuntimeEvent、source map 跳转和减少动效状态。

检查方法：人工视觉检查 + 组件/E2E + 事件 Schema 测试。

## U04. 多选积木保存为个人蓝图并重新使用

前置条件：画布含多个相连顶层栈和至少一个外部依赖。

用户操作：

1. 使用 `Shift + 左键` 逐个加入/移出选择。
2. 使用空白左键拖动框选另一组积木。
3. 拖动已选积木并使用鼠标中键平移画布。
4. 右键选择“保存为蓝图”，处理外部依赖提示。
5. 在新项目中插入个人蓝图并展开。

预期结果：

- 点击多选不误触发拖拽；中键始终平移画布。
- 保存时保留多栈相对位置；外部依赖被公开为插槽或阻止保存。
- 新实例生成新稳定 ID，保留来源/版本，不引用原项目私有对象。
- 展开/封装和整个操作可撤销。

证据：选择集合、坐标、蓝图清单、依赖诊断、插入前后 ID 和撤销记录。

检查方法：人工鼠标流程 + 组件/E2E + 序列化契约测试。

## U05. 配置模型/知识资源且秘密不进入项目

前置条件：模型和知识积木可配置；准备无密钥和用户安全配置两种环境。

用户操作：

1. 双击模型积木打开配置。
2. 设置 Provider 类型、Base URL、模型 ID、超时和项目覆盖。
3. 在 Blocky 安全存储或本地 `.env` 配置测试密钥。
4. 运行连接测试并保存、导出、查看诊断包。

预期结果：

- 界面显示配置来自应用、项目、资源还是积木覆盖，并可恢复继承。
- API Key、Token、Cookie、私有地址和敏感请求头不进入 Workspace、IR、蓝图、项目导出、日志或诊断。
- 无密钥时给出可恢复诊断；需要 live 验收时主动请求用户在安全位置配置，不要求在聊天粘贴。

证据：配置来源界面、连接测试结果、四目标敏感扫描计数和项目导出摘要。

检查方法：人工配置 + L3 秘密隔离/迁移/重置/负例自动化。

## U06. 对锁定 GitHub 快照生成自定义积木或蓝图

前置条件：本地只读、锁定 commit 的小型公开项目夹具；不执行依赖安装脚本。

用户操作：

1. 从“项目积木化”入口选择夹具。
2. 查看来源、commit、许可证摘要、入口和副作用。
3. 查看系统建议的“自定义积木/蓝图/兼容草案/原生保留”。
4. 查看源码符号到积木的证据和未覆盖项。
5. 接受一个幽灵差异并运行确定性测试。

预期结果：

- 输出类型选择有理由，不把整个仓库塞进一个不透明代码积木。
- 优先复用现有核心积木；生成的自定义接口包含类型、错误、权限、依赖和资源预算。
- 接受前不改变项目；拒绝后项目字节级不变。
- 结果可编译、可展开、可定位来源，并保留许可证/commit。

证据：SourceSnapshot、ConversionEvidenceMap、ConversionPlan、SemanticPatch、编译/测试结果。

检查方法：人工审阅 + golden fixture + 差异指纹/拒绝不变测试。

## U07. 保存、关闭、重开并继续编辑

前置条件：包含蓝图、知识资源引用、转换来源和一次运行摘要的项目。

用户操作：保存，关闭应用，重新启动并打开项目；继续修改并再次运行。

预期结果：Workspace、稳定 ID、蓝图来源、资源引用和转换证据摘要无损；IR、清单和诊断重编译验证；大型索引不写入项目 JSON；恢复后无孤立临时状态。

证据：保存前后规范摘要、Host 返回、重编译结果和重开运行轨迹。

检查方法：原生 E2E + 项目格式/Host L3 测试。

## U08. 摄取真实资料、增量更新并删除失效内容

前置条件：真实文件、URL 或仓库来源；隔离知识存储；无敏感生产数据。

用户操作：添加来源，首次同步；修改部分内容；删除一份文档；改变权限范围；再次同步。

预期结果：只重新解析和索引变更片段；删除和权限变化传播到检索；来源 ID、页码/行号和 commit 可追踪；部分失败不会把旧索引误报为最新。

证据：新增/更新/删除/跳过数量、索引版本、失败项和检索前后对照。

检查方法：人工流程 + 增量同步、幂等、删除传播和中断恢复测试。

## U09. 执行真实检索、重排、引用和无证据拒答

前置条件：已建立质量问题集，包含有答案、无答案、权限隔离和精确关键词问题。

用户操作：分别运行关键词、向量和混合检索；开启/关闭重排；检查引用；询问无证据问题。

预期结果：Top-K、过滤、阈值、重排和降级可见；引用定位到真实来源；无证据时按蓝图策略澄清或拒答；不泄漏无权限文档。

证据：候选和分数摘要、排名变化、引用覆盖率、质量评分、P50/P95 和权限负例。

检查方法：人工质量集 + 确定性规则测试；需真实模型时按 U05 安全协作。

## U10. 转换真实公开 GitHub 组件项目

前置条件：用户选定公开仓库和 ref；网络访问、缓存目录和许可策略已批准。

用户操作：获取不可变快照，选择子目录，执行只读分析，审阅产物计划，运行基准，接受生成结果并在画布改造。

预期结果：快照可重放；不运行仓库安装脚本；大对象以工件引用返回；代码、蓝图、适配器和保留项边界合理；用户修改不会被上游升级静默覆盖。

证据：仓库/commit/依赖锁/许可、证据覆盖率、性能预算、生成包、升级差异。

检查方法：人工审阅 + 多语言 fixture、供应链负例、取消/恢复和跨版本测试。

## U11. 使用 Codex、Claude Code、OpenClaw 夹具验证 Harness 映射

前置条件：分别锁定来源和版本；Codex/OpenClaw 源码与行为夹具；Claude Code 公开配置/扩展/行为夹具。

用户操作：导入规则、Skills、工具/MCP、权限、子 Agent、Hooks/插件和会话；比较原生与 Blocky 表达；执行固定任务。

预期结果：通用语义复用核心积木；未知能力进入原生保留；Codex/OpenClaw 可按自身矩阵评定；Claude Code 未完成源码/许可证审计前不宣称完整源码转换或内置兼容模板。

证据：结构、配置往返、行为轨迹、权限翻译、未覆盖和升级/恢复报告。

检查方法：每个 Harness 独立人工流程和契约测试；一个通过不能代表其他项目。

## U12. 大型代码库/知识库的性能与取消恢复

前置条件：小型课堂资料、中型团队知识库、大型代码仓库三个公开或合成数据档。

用户操作：首次扫描/索引；增量修改；并发检索；中途取消；重启后恢复。

预期结果：满足当阶段批准的加载、内存、索引体积、P50/P95 和取消预算；UI 不冻结；大仓库按需解析；恢复不重复外部副作用。

证据：冷/热指标、峰值内存、缓存命中、工件大小、取消时延和恢复记录。

检查方法：自动性能/长稳 + 人工交互流畅度；具体阈值在对应开发任务验收前与用户确认。

## U13. 键盘、鼠标、菜单和上下文操作完成同一任务

前置条件：包含多个栈、蓝图、自定义积木和运行事件的项目。

用户操作：分别用顶部菜单、命令中心、快捷键和右键完成复制、分组、保存蓝图、配置、断点和从此运行；再只用键盘完成核心任务。

预期结果：所有入口读取同一命令定义；启用状态和错误原因一致；弹层不重叠；焦点、撤销和快捷键冲突正确；鼠标中键、滚轮、框选和 `Shift + 左键` 符合计划。

证据：命令 ID/上下文、焦点轨迹、撤销日志和键盘操作录像。

检查方法：人工桌面体验 + 命令系统契约/E2E/可访问性测试。

## U14. 非法仓库、恶意依赖、越权、密钥和日志负例

前置条件：包含路径穿越、超大文件、符号链接环、混淆脚本、恶意安装钩子、许可证缺失、密钥样本和越权过滤的隔离夹具。

用户操作：尝试扫描、生成、运行、导出和查看诊断。

预期结果：默认不执行安装脚本或仓库代码；越界和不明许可证阻止可运行产物；秘密不回显；错误只给稳定代码、路径类别和恢复建议；已生成项目不因转换失败损坏。

证据：拒绝代码、敏感扫描、普通包隔离、项目摘要和恢复检查。

检查方法：L3 安全负例、供应链扫描、Host/沙箱和日志脱敏测试。

## U15. 多画布创建、跨画布连接、导航和保存重开

前置条件：支持 Project Manifest、多个模块 Workspace 和画布项目标签；准备一个对话 Agent、一个资料检索模块和一个无模型自动化模块。

用户操作：

1. 分别在三个画布标签创建模块并重命名、固定、移动标签。
2. 从 Agent 画布引用检索模块和自动化模块，使用类型化入口传入/返回数据。
3. 双击跨画布引用打开目标，再使用“返回来源”回到调用点。
4. 修改目标显示名，验证引用；再删除一个导出或改变接口，查看诊断和影响分析。
5. 保存、关闭、重开项目，并从标签搜索/Project Map 恢复导航。

预期结果：

- 不要求将多个 Agent 或模块放入同一画布；打开标签和顺序不会改变运行结果。
- 引用保存稳定 `moduleId`/`exportId`，显示名变化不破坏连接；目标删除或接口变化产生可定位错误，不按名字猜替代项。
- Project Map 只做导航和影响分析，不能绕过画布直接改变运行语义。
- 单画布旧项目可显式迁移；多画布保存重开后 Workspace、稳定 ID、跨模块引用和项目资源无损。

证据：Project Manifest 摘要、Module/Project IR、引用诊断、导航栈、迁移报告和保存前后规范摘要。

检查方法：人工标签/导航流程 + 模块链接/迁移契约 + 原生保存重开 E2E。

## U16. 默认零页面，明确要求后创建并操作应用界面

前置条件：一个已完成但没有 AppSurface 的 Agent 项目；构建助手和应用界面计划/差异接口可用。

用户操作：

1. 新建并运行 Agent，不提出页面需求，检查项目和标签。
2. 明确要求“为这个 Agent 创建一个工单操作页面，只在本地预览”。
3. 审阅 AppSurfaceManifest、FrontendBridgeContract、依赖和前端文件差异；先拒绝一次，再重新生成并接受。
4. 在浏览器标签完成输入、附件、提交、流式输出、取消和人工确认的真实操作流程。
5. 关闭浏览器标签、重新打开页面，并与第二个项目同时预览；最后停止预览。

预期结果：

- 第一步 AppSurface 数量为 0，不产生前端目录、浏览器标签、依赖或构建任务。
- 拒绝后项目字节级不变；接受后才出现页面产物，且关闭标签不删除页面。
- 页面只能调用 Bridge 清单声明的入口，不能访问 Tauri 全局对象、任意 Host、文件系统、Shell、安全存储或 Agent 隐式工具权限。
- 两个项目的 Cookie、LocalStorage、下载和调试会话隔离；停止/空闲回收后不遗留预览服务。
- 创建页面不自动增加登录、数据库、域名、发布或部署。

证据：创建前后 Project Manifest、文件差异指纹、拒绝不变摘要、Bridge 调用轨迹、浏览器存储检查和预览进程清单。

检查方法：人工真实页面操作 + 文件差异/安全契约 + 隔离浏览器 E2E + 预览生命周期检查。

## U17. Agent + RPA 有人值守企业流程

前置条件：阶段 7 attended RPA；隔离测试桌面应用或网页；无真实生产账号和敏感数据。

用户操作：

1. 在独立自动化画布连接测试应用/窗口，使用语义或 UI Automation 定位表单元素。
2. 主动开始录制一段读取、填写、等待和校验流程，故意经过密码/验证码字段。
3. 审阅幽灵积木，删除或替换敏感步骤，加入人工确认、错误处理和检查点。
4. 让 Agent 调用该自动化模块，运行中暂停、恢复、停止，并模拟元素改名、窗口变化和网络中断。
5. 仅在语义/UIA 失败时尝试图像或绝对坐标回退。

预期结果：

- RPA 可不依赖模型独立运行，也可作为 Agent 的类型化工具；权限按应用、窗口、目标、动作和数据范围展示。
- 密码、Token、验证码和隐私字段不进入录制工件、截图或轨迹，只保留秘密引用或人工输入步骤。
- 定位器失败时暂停并要求修复，不点击相似位置；绝对坐标回退有持续可见的高风险警告。
- 恢复从显式检查点继续并重验外部状态；已完成副作用不被盲目重放，停止后输入设备和应用会话释放。
- 阶段 7 不出现无人值守 Worker、机器池、企业凭据或计划任务入口。

证据：RPA 模块、定位器摘要、权限计划、敏感扫描、运行轨迹、检查点、副作用记录和停止后的资源清单。

检查方法：人工桌面流程 + UIA/浏览器定位测试 + 权限/隐私/恢复/幂等 L3 负例。

## U18. Windows 通知区域、后台运行和真正退出

前置条件：Windows 正式构建；通知区域图标、单实例、窗口状态和至少一个可取消的长运行任务可用。

用户操作：

1. 点击最小化，确认任务栏/通知区域行为；通过通知区域图标恢复并聚焦窗口。
2. 启动一个已授权长任务，再最小化；从通知区域查看脱敏摘要、暂停和继续。
3. 在有未保存内容和运行时点击关闭，分别验证“返回”“停止并退出”和允许时的“保留后台运行并隐藏”。
4. 在多显示器/不同 DPI 下保存窗口状态，移除显示器后重启；再启动第二个实例。
5. 从通知区域选择“退出”，检查所有进程、端口、文件锁和图标。

预期结果：

- Windows 默认最小化到通知区域，可在设置中改为任务栏；最小化不会自动启动任务、扩大权限或等同退出。
- 只有用户已启动且允许后台继续的任务可在隐藏时运行；Tooltip/摘要不显示 Prompt、文件名、联系人、模型输出或错误正文。
- 关闭保护与项目脏状态、运行状态一致；第二实例把参数交给现有实例并恢复主窗口。
- 窗口总能恢复到可见工作区；通知区域退出后 Host、sidecar、预览服务、托管运行时和图标全部结算，无孤儿进程。

证据：窗口状态机事件、通知区域菜单状态、进程/端口/文件锁清单、单实例交接、多显示器恢复和退出后资源扫描。

检查方法：Windows 原生人工流程 + 窗口/单实例 E2E + 后台长稳 + 退出资源审计。

## U19. 底部面板、终端、运行日志与诊断导出

前置条件：正式 Windows 构建；底部面板、确定性运行夹具、用户终端 Host、具名任务、结构化日志总线和脱敏诊断导出可用。

用户操作：

1. 打开一个同时包含编译错误、配置警告和跨模块引用问题的项目，通过状态栏打开“问题”，逐条定位到对应画布、积木和设置字段。
2. 修复问题并运行确定性 Agent；观察积木绿色激活、黄色警告、红色错误与“运行日志”行，点击日志进入运行轨迹，再跳回来源积木。
3. 新建两个用户终端，分别执行短任务和持续产生大量输出的具名任务；验证重命名、拆分、筛选、取消、退出码、截断提示和活动任务关闭保护。
4. 让 Blocky 构建助手和作品 Agent 分别请求一个允许的进程任务，再尝试读取、附加或向用户终端发送输入。
5. 触发编译器、Provider、应用界面预览、RPA 和扩展错误，在“输出”按具名通道与关联 ID 筛选，并从错误跳到来源。
6. 在测试输入中放入模拟 API Key、Token、Cookie、Authorization 头、私有路径、Prompt、模型正文和验证码，复制日志并导出诊断包。
7. 收起底部面板并最小化到通知区域，确认已授权任务继续且可观察；随后真正退出并检查 PTY、子进程、端口、日志句柄和临时文件。

预期结果：

- “问题”只读取结构化 `Diagnostic`；运行高亮、运行日志和运行轨迹读取同一 `RuntimeEvent`，状态、顺序、来源与关联一致。
- 隐藏或切换底部标签不停止任务、不清除日志、不改变项目字节；停止运行、终止终端、清除显示和清除持久诊断是不同命令。
- 大输出不冻结画布、不阻塞子进程；截断、分级丢弃和写盘失败均产生可见诊断，警告/错误和审计元数据不被静默丢弃。
- 用户终端与 Agent 进程工具物理隔离；Agent 只能通过独立的类型化 `AgentProcessRequest` 和 Host capability 执行允许任务，无法读取终端输入、历史、环境值和 PTY 输出。
- 项目、前端日志、Host 日志、复制内容和诊断包不包含测试敏感值或不必要的本机绝对路径；项目普通导出不包含日志、终端历史或审计记录。
- 真正退出后无 PTY、任务子进程、日志刷新器、文件句柄、预览服务或不可见 Host；重新打开项目不会把旧日志当作项目运行事实。

证据：底部面板操作录像、Diagnostic/RuntimeEvent/LogEnvelope/AuditRecord 关联摘要、终端 Host 会话记录、背压与截断计数、四目标敏感扫描、诊断包清单和退出后资源扫描。

检查方法：人工桌面流程 + 组件/契约测试 + Windows PTY 原生 E2E + 大输出性能/长稳 + L3 权限隔离与敏感扫描。
