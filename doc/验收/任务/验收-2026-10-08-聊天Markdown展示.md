## 详细报告

### MD01 两种助手回复可读

#### 场景：阅读构建助手完成、流式及重开后的回答，阅读 Blocky Agent 回答

标题、粗体、列表、引用、分隔线、行内代码、代码块和 GFM 表格正确显示；未闭合流式片段不报错，完整回答保持内容。历史原文不改写。必须分别验证两个真实面板，不能只验独立渲染组件。

### MD02 窄栏代码及表格阅读

#### 场景：240px 与常用栏宽阅读多行正文、长代码及宽表格

正文不挤出聊天区域；代码保持缩进，代码/表格在本区域横向滚动且可键盘聚焦。菜单、输入与发送控件可用，滚动可读到末尾。

### MD03 既有交互及内容边界

#### 场景：继续发送、停止、审阅或撤销修改，阅读带 HTML 的回答

用户输入、差异内容保持原文；发送、停止、撤销与引用入口保持既有行为。回复中的 HTML 不执行，危险 URL 与相对页面链接不可导航；远程图片不自动加载。实际测试与合成模型响应分别标记，不把本地模拟称为外部 API 成功。

问题与风险：待独立验收填入。普通包证据须绑定构建来源；源码浏览器不替代普通 Windows 包。
