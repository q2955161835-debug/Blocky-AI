## 详细报告

### C3-R01：参数遮蔽未纳入函数调用解析（P2）

位置：`packages/conversion-core/src/numeric.ts:118`。

`CallExpression` 分支直接通过 `functions.get(name)` 查找顶层函数，未先判断同名标识符是否在当前 `environment` 中。`environment` 表示当前形参与已替换的实际数值参数；在 Python/JavaScript 中，同名形参应遮蔽顶层函数。因当前运行契约要求所有入参为数值，对该参数的调用在原程序中并不可执行，但 lowering 会错按全局纯函数展开，生成成功的算术结果。

该问题不会引入任意代码执行，却违反“只接受可证明等价的封闭纯数值函数”边界。建议在静态解析调用目标时先处理作用域；当前子集可直接拒绝 `environment.has(name)` 的调用。此为源码推理发现，未构造或执行样例，需实现方用既有测试框架验证后提交。

### C3-R02：source() 与候选 provenance 校验不完全一致（P3）

位置：`packages/conversion-core/src/scan.ts:323`、`packages/conversion-core/src/candidate.ts:69`。

`analyze()` 对 page 的 snapshotId、commit、artifactId、sha256、bytes、subdir、repository、dirty 逐项与输入 artifact 比较；`source()` 只比较 snapshotId/sha256。`realConversionCandidate()` 虽重新读取源码并调用 analyzeFile，但仍从输入 report.artifact 直接填入 commit、version 等 provenance 字段，也只重新核对 report 中列出的许可证。

目前 CLI 在 candidate 前先执行 analyze，桌面使用本次生成的 report，因此不将此描述为已证实可达的权限绕过或已复现的缓存攻击。它是可复用 candidate/source API 自身的防御性一致性缺口：调用方替换 report 元数据时，源码 hash 一致并不足以保证所有归属字段可信。建议 source/analyze 共用完整 artifact-header 校验，候选 provenance 从重新验证后的 Host header 获取；未来若允许载入报告，许可证集合也需从完整快照重建，而非只核对调用方列出的项。

### 其他边界的源码观察

原生 `knowledge/repository.rs` 仅允许 rev-parse/ls-tree/cat-file，使用 no-optional-locks、no-replace-objects、no-lazy-fetch、no-pager、literal-pathspecs，清理继承的 GIT 环境配置并禁协议；未调用 status/diff/filter 或安装/执行上游依赖。转换子目录为字面路径且要求真实目录前缀；根目录须为仓库顶层；来源 tree 路径拒绝 Windows drive/ADS/backslash/dot 语义。symlink/submodule、秘密文件、二进制及超限内容进入排除集合。dirty 明确为选定已跟踪文本的原始字节比较，未检查项为 unknown，不宣称等同 Git status。

`ConversionStore` 将有效 projectId hash 后作为独立 scope，各 scan/read/cache/cancel 请求传递项目参数。metadata 内容 hash 绑定 art ID、snapshot ref 绑定同一 artifact、snapshot.jsonl 完整 hash 校验，分页文件还核对 bytes/hash。工件上限 240 MiB、metadata 32 MiB、页 4 MiB/64 文件、总文件 20000、cache 16 MiB；TS 校验总源 100 MiB、文件 2 MiB、累计数量和递增 cursor。缓存只作为派生分析，候选重新解析原始源码；cache hash 为完整性校验，不是带密钥认证。

`expression.ts` 接受精确字段形状、有限数值与有限参数名，节点数 256、深度 32、参数 16；算术结果绝对值不超过 1e9，拒绝除零/非有限值。未发现 eval、动态函数调用或 I/O 路径。`analyze.ts`/`numeric.ts` 对解析错误、非函数顶层、递归调用、非允许语法实行原生保留，但 C3-R01 需要补齐作用域判定。

上述为静态控制存在性检查，不代表真实 Windows 路径竞态、取消边界、跨进程缓存篡改、分页超限或真实 Git 配置行为已被本轮独立执行证明。
