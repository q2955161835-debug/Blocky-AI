#### 1. 运行来源与隔离

候选 3 CLI 分别执行 project create --template research-companion、code-guide、knowledge-tutor、task-helper。四个结果各自有独立 projectId 和项目文件。随后以独立 CLI 进程对四个文件分别执行 project validate、project compile、project inspect；另外对 task-inserted 和 personal-reinserted 也执行同样三项。所有结果 ok=true，validate/compile/inspect 的 diagnostics 均为空。每次 CLI 进程重新从磁盘读取项目，因此这些结果核对了保存工件在跨入口重新打开后的结构和编译状态。
