## 详细报告

### 1. 项目创作与编辑

#### S1-01：从欢迎页创建两个模块并稳定导航

步骤：从资料问答伙伴蓝图新建项目；打开两个画布；按链接跳转至目标并返回；重命名目标模块后再次跳转。

通过标准：两个真实 Blockly Workspace 独立可编辑；引用只使用 moduleId/exportId，重命名不改变目标；新项目 appSurfaces 为零；关闭标签不删除模块；打开标签与排序不改变 ProjectIR 语义。项目包不能运行时导入尖峰源码。

证据：普通应用操作记录、Manifest/Workspace 无秘密摘要、编译前后链接对照。失败判据：只展示静态图、按标题猜引用、只构造假的 ProjectIR 或关闭标签删模块。

#### S1-02：修改角色、资料和回答方式并修复错误

步骤：分别修改角色、知识资源和回答方式；制造缺失导出错误；通过问题面板定位原块，再恢复导出。

通过标准：三个配置值进入真实编译/运行输入；缺失导出只报告根因 `BLK-LINK-002`，带来源；修复后诊断消失；菜单/命令中心/快捷键/右键共享命令启用条件；中键平移、指针缩放和搜索可用。

证据：配置读回、输入变化断言、问题面板跳转及修复证据。失败判据：设置无消费者、解析错误文案猜来源、静默自动重连。

#### S1-04：多选并复用个人蓝图

步骤：Shift 点击多选与取消一块；空白框选；整体拖动；保存两组顶层栈；重新插入、展开、一次撤销。

通过标准：Shift 点击不触发拖拽；移动保持相对布局；插入 ID 全部重新生成；原子块可继续编辑；必需外部依赖转成插槽或阻止保存；一次撤销恢复插入前项目。

证据：选择与布局操作、插入前后 ID 集合和撤销摘要。失败判据：ID 冲突、丢失栈、无效外部依赖被悄悄接受。

### 2. 运行与资源配置

#### S1-03：运行问答、警告、失败和取消

步骤：输入有证据及无证据问题；触发确定性警告、工具失败和取消；从日志定位轨迹和源块；开启减少动效重验。

通过标准：回答经过配置、检索、引用链；无依据不编造；高亮、日志、轨迹来自同一 RuntimeEvent 序号和 source map；绿/黄/红与图标文字一致，不改变积木尺寸；取消传播，终态后无执行事件。

证据：当前运行事件、引用对照、可见状态及来源跳转；明确记录确定性适配器。失败判据：把预录事件直接当执行、固定成功文案、三套状态不一致或取消后继续执行。

#### S1-05：配置资源但不携带秘密值

步骤：绑定项目知识资源与不可用的虚构 secretRef，保存重开；测试缺失资源、错误 scope 与未授权工具；扫描 Workspace、项目包、事件与日志。

通过标准：引用恢复一致；来源与继承层可读回；缺失或越权失败关闭；不把引用当凭据、不自动调用网络；四目标无秘密值。使用明确虚构测试标记，不读取或导出本机真实凭据。

证据：资源解析和拒绝事件、无内容泄露的扫描摘要。失败判据：WebView 接收密钥、scope 猜测回退、权限不足仍调用适配器。

### 3. 安全变更与持久化

#### S1-06：审阅锁定仓库候选

步骤：打开固定仓库快照的提交/许可证/依赖和源码证据；生成候选；先拒绝，再接受另一份合法候选；另测基线过期、无效引用与事务失败。

通过标准：可解释自定义积木或蓝图选择；预览不改项目；拒绝和失败后原文件集合、字节及摘要不变；权限差异独立批准；接受后重编译且可撤销；不执行仓库代码。

证据：锁定来源、差异、前后文件清单和 SHA-256。失败判据：预览产生写入、部分事务落盘、仅显示“不变”却不比较字节。

#### S1-07：原生保存重开与写入失败恢复

步骤：编辑两个模块并设置本机会话；保存、关闭、重开；另测写入失败、损坏输入、未知版本、路径穿越和派生缓存篡改。

通过标准：项目事实无损重开并重编译；会话独立恢复且损坏不破坏项目；原子写入失败保留旧文件；前端不能任意访问路径；项目不含日志、终端历史或会话状态；尖峰项目不得静默当正式格式打开。

证据：Host 测试、原生重开操作、文件集合/字节比较。失败判据：仅内存往返、只比内存对象、信任缓存或读写越界。

### 4. 页面与桌面运行

#### S1-08：显式创建应用界面

步骤：普通 Agent 请求、显式页面请求后拒绝、显式页面请求后接受；打开/关闭预览；切换另一个项目并测试存储与 Bridge 边界。

通过标准：前两种仍零页面且字节不变，接受后从零到一；差异含源文件/依赖/权限；关闭标签保留产物；跨项目 Cookie/存储不共享；未声明端点与 Tauri/文件/Shell 访问被拒绝；无隐式部署。

证据：文件差异、实际预览、隔离负例及资源回收。失败判据：按钮直接插入页面、共享浏览器状态或桥接越权。

#### S1-09：最小化、恢复、关闭保护和真正退出

步骤：启动已授权长任务，最小化到通知区域并恢复；检查菜单；测试脏项目关闭的返回/隐藏/停止退出；启动第二实例；真正退出。

通过标准：隐藏不中断原任务且不能隐式启动新任务；恢复回原项目；关闭保护有效；第二实例只转交；退出先停止新请求，取消/刷新/关闭后才标记 exited；系统读回无遗留本次创建的进程、端口、管道与锁。结算失败停留退出中并可操作。

证据：通知区域真实操作、任务事件、退出前后系统进程/端口/锁读回。失败判据：只测状态机、手动写零计数、窗口消失却有残留进程。

### 5. 输出与产品交付

#### S1-10：四视图面板、具名任务和脱敏导出

步骤：问题定位；运行日志跳转；运行锁定具名任务至输出截断、取消及异常退出；通道筛选；折叠面板；清除视图、清除存储及显式导出；提交 Agent 附加用户终端负例。

通过标准：四视图分别消费正式协议；预算按字节执行且截断有结构化标记；任务参数/平台/权限/并发/超时有效；Agent 不得读取或控制用户终端；折叠不停止任务；日志先脱敏后分发；高级别丢弃可见；导出再次脱敏且排除敏感正文。

证据：任务生命周期、背压结果、拒绝码 `BLK-TERM-003`、日志拒绝码 `BLK-LOG-004` 和导出清单。失败判据：文本推断业务状态、任意 Shell 后门、只在前端遮罩、项目包夹带日志。

#### S1-11：普通 Windows 包和完整旅程

步骤：冻结交付提交，构建普通 Windows 产物；按上述场景完整走通；运行正式 Core/Full 门禁与十个契约夹具；检查产物依赖、测试钩子及敏感类别。

通过标准：所有必需项通过；普通包不包含 WDIO capability、测试入口、远程代码或秘密；正式根构建不依赖尖峰路径；记录产物字节数与 SHA-256；性能依据原 Core 阈值；Full 不少于 360 个 5 秒循环及 30 次真实 Host 保存重载。CI 未在线执行时单列“未执行”，不凭工作流文件存在声称远端通过。

证据：提交、命令/退出码、测试汇总、当前普通包截图及产物哈希；API 真实性单列“否”。失败判据：复用历史验收、仅开发服务器成功、缩短长稳却标完整通过。

## 独立执行与结论填写规则

由未参与对应实现的 Agent 执行；局部普通验收使用 luna + xhigh，最终复杂验收使用 sol + medium；涉及安全/隐私分项使用不低于 astra + medium。主 Agent 负责修复与交付状态，不冒充独立验收。

同一事实只在所属编号记录，其他场景引用该证据；局部通过不能提前标本表最终通过。正式记录增加执行人、精确提交、产物哈希、测试命令及证据路径；只保留本任务范围。最终结论限项目规则允许的六种值，有条件通过不得默认合并或发布。
