## 详细报告

### 用户功能：查看失败构建的调用记录

#### 场景：记录实际用量而不保存正文、请求头或密钥

`response_metadata` 只投影 provider/model/responseId、三类 Token 数及 finishReason；不会复制 message、error body、请求头或完整供应商响应。`Evidence`、`Attempt`、`ResponseMetadata` 反序列化均拒绝未知字段。写入前与读取后执行白名单、额度、状态和凭据形状检查。

本轮独立运行现有 Host 元数据测试，含 synthetic-private-body/header 的响应投影不包含 private 标记；未知字段和额外读取参数均拒绝。独立 Rust 探针用真实 Host 连续执行三个无密钥 explain 会话，读回文件不包含 prompt 标记。将常见 `sk-` 形状放入 responseId 后读取拒绝。没有把已知类型的凭据形状检测外推为任意未知秘密检测。

#### 场景：不把前置失败或矛盾记录描述为成功调用

错误汇报 1（已修复）：首轮把 `networkAttempted=false` 与含实际模型/Token 的 response 同时写入 latest.json，真实 `builder-evidence` 接受，读回 `contradictoryEvidenceAccepted=true`。实现方增加 session/attempt 完成态、时间顺序及 network/response 交叉校验后，原失败输入读回 `false`；独立倒序完成时间负例也被拒绝。

错误汇报 2（已修复）：首轮源码中 marker 在 `send_raw` 的前置取消/密钥编码检查前运行，存在把前置失败记为网络尝试的路径。现在 marker 位于请求成功构造后、`client.execute` 前，biased select 优先取消；当前 `rejected_preflight_never_marks_network_attempted` 实测预取消和非法 UTF-8 key 均返回错误且 marker 未调用。该子项使用无网络模块单测与调用链核对；没有执行真实 Provider 请求。一次独立 bin 尝试直调私有 generate 被编译可见性拒绝，未运行、未接触秘密存储；已删除该不可用临时 bin。

`networkAttempted` 只表示已进入发送尝试，不表示供应商已接受、计费或成功返回。只有读回实际响应元数据才能判断真实响应。证据文件不提供防篡改签名，不宣称阻止拥有本机同等写权限者构造完全自洽的伪记录。

### 用户功能：保留最新记录并按请求读取

#### 场景：连续覆盖、拒绝跨请求和链接路径

真实 Host 在 Windows 三次运行固定侧车，逐次覆盖 `latest.json` 并以新 requestId 读回完成态；原子写使用同目录临时文件、sync_all 与 persist。跨 requestId、未知字段、额外读取参数拒绝。读取 API 仅返回记录，不调用 Builder、Provider 或审批入口；GUI 只有 active requestId 仍匹配时展示失败记录，clear/generate 清除旧状态。

独立创建真实目录 junction 和文件 symbolic link：两者读取均拒绝；使用真实 BuilderHost 向两种链接路径启动会话均失败，链接目标前后字节一致。三个合法会话随后仍连续成功。本轮未测试恶意同用户进程在检查与文件打开间实施竞态替换，不把静态链接负例外推为系统级攻击防护。探针链接测试后已删除，目标夹具保留在 `try/stage5/security/evidence-probe/`。

Tauri 读取入口调用 `window_lifecycle::visible`，要求 main 窗口、可见、非最小化、未退出。CLI 固定 `builder-evidence` 请求形状，不接受调用方文件路径。

### 用户功能：接受合法助手补丁并拒绝越权

#### 场景：共享 Schema 进入真实 SDK dispatch

生成脚本直接把共享 `builderOperationSchema` 和 `surfaceSpecSchema` 转为 JSON Schema，操作对象拒绝额外字段；SDK 后仍执行共享领域会话的目标模块、操作、意图和权限检查。

独立探针通过 `runBuilderEngine` 的真实 Pi dispatch 路径：合法 block.update 产生验证通过的候选；操作顶层多余 command、payload 内多余 shell、跨 moduleId 和 shell.execute 四类负例均失败。每个场景前后项目字节相同，未写项目，也未调用真实模型。
