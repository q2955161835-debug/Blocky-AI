## 详细报告

### 用户功能：使用息壤模型

#### 场景：不能用请求字段绕过 Host 资源绑定

独立 Rust 探针直接链接真实 `blocky_studio::provider::ProviderHost` 与 `BuilderHost`，使用项目内隔离 UserStore。合法息壤请求的 preflight 读回 `https://ai.ctaigw.cn/v1/chat/completions`，且预览不包含 secretRef。分别替换 provider、secretRef、resourceId、modelId 后拒绝；请求追加 endpoint/baseUrl/headers 字段时严格反序列化拒绝。

九个资源 baseUrl 负例覆盖 HTTP loopback、HTTPS IPv4/IPv6 loopback、RFC1918 地址、云 metadata 地址、域名后缀伪装、userinfo 伪装、重定向 query 及官方 DeepSeek 地址，全部在 Host preflight 拒绝。地址匹配后仍使用 Host 常量发送，不使用资源字符串组装网络目标。密钥引用绑定意味着请求不能自行切换至另一资源的引用；本报告不声称阻止拥有本机资源编辑权限的用户主动重新配置密钥。

### 用户功能：批准构建请求

#### 场景：批准后更换 Provider、模型或密钥引用

先对合法息壤资源调用真实 Builder preflight 获取 digest，再分别改变 Host UserStore 的 provider、modelId、secretRef，携带旧 digest 调用真实 Builder run，三次均为 `BLK-PERM-001`；目录中没有创建 builder-evidence，证明在 sidecar 启动及网络尝试前拒绝。固定 BuilderRequest/原项目摘要与 ProviderRequest 摘要共同参与审批摘要，CLI ledger 与桌面确认取同一 preflight digest，run 重读资源并复核。

桌面确认源码显示 Host 读回的 Provider、端点、模型和预算。本专项未操作 GUI，因此这一项为源码边界确认，不构成普通候选视觉验收。

### 用户功能：查看调用记录

#### 场景：失败响应保持息壤归属且不持久化正文或请求头

探针 build.rs 每次从当前真实 evidence.rs 提取 metadata 定义和函数前缀编译，不维护复制版校验逻辑；同一合成响应包含伪造 provider、正文和 Authorization 哨兵。以 Host 的 xirang 参数抽取后 provider 为 xirang，正文/请求头哨兵均不在结果中；未知 provider 参数拒绝。保留 API 实际返回的模型名、ID、用量和结束原因，未把这些合成数据作为真实 API 事实。

源码调用链核对：Provider builder 在安全存储闭包内取得密钥，直接交给 transport；响应 metadata 的 provider 来自已绑定 ProviderRequest。普通 Runtime 成功结果也在解析后覆盖为真实 Host 路由的 provider。新增 provider 字段未引入秘密值到 WebView、sidecar IPC 或 evidence。sidecar 仍接收既有资源定义和秘密**引用**，不是秘密值；模型 inspect 仍按既有投影处理。这里没有重新执行浏览器、sidecar 或四目标完整秘密扫描。

### 用户功能：控制网络请求并保留既有路径

#### 场景：重定向与非 live 请求

生产 transport 保持 `https_only(true)`、`no_proxy()`、`redirect(Policy::none())`，新端点仅来自两个 Host 常量。定点运行现有真实本机 HTTP mock 测试，302 带 Location 仍返回 `BLK-PROVIDER-HTTP`，未转为目标连接失败；同一测试中的成功、认证、限流、服务及坏 JSON 路径通过。mock 专用客户端允许本机 HTTP，不能据此声称对远端 TLS/证书或 DNS 环境做过测试；生产 HTTPS 约束由源码核对与固定目标拒绝探针支持。

未声明 provider 的旧请求仍解析为 deepseek 并读回官方端点；确定性 Builder preflight digest 等于原 start.digest。Runtime 新增 xirang-v1 后仍调用同一 nativeAgentServices/generate 路径，继续保留 live 禁用、用户资源、协议、参数白名单、1024 输出上限、审批、取消和后续响应护栏。没有新增任意端点执行器。
