### 蓝图

#### B01 整块折叠及高度

通过标准：个人蓝图、导入、更新/还原、项目画布、内置起始蓝图一起收纳为“蓝图”，普通新进程默认折叠；展开后上述入口可用，拖动上边界能改变高度且画布保留有效空间。验证实际工作台，不挂独立组件替代。

验证结果：通过。run2 实际工作台默认整块收起，展开包含个人蓝图/导入/更新还原/项目画布及五起点。run10 普通 WebView 真实 pointer 拖动上边界，200px→268.998px；随后可折叠，画布保留有效空间。新进程 run4 默认仍收起。

### 聊天输入

#### C01 增长、上限及手动高度

通过标准：Blocky Agent 与构建助手输入均随多行内容向上增长，默认最高不超过所在右栏聊天区域的 40%；达到上限后输入框内部可滚动，实际输入时 caret 可见。拖动输入框上边界调整高度，空闲及清空后手动高度保留；实际窄栏与常用栏宽均可发送。

验证结果：通过。两面板 85 行实际输入，输入区域 297.996px / 面板 747.421px（≤40%），框内 scrollHeight=1667、clientHeight=253、末端 caret 及 scrollTop=1413.968；清空后手动高度 118.998px 保持。run10 实际 pointer 拖动两输入框，均 98.998px→147.996px。没有操控系统窗口拖动，因此不追认 P04。

### 聊天阅读

通过标准：输出占输入外余下空间；两助手实际增量输出时，位于底部继续跟底；用户向上翻阅时新输出不拉回，主动回到底部后恢复跟随。截图与滚动位置读回必须来自普通工作台两面板。

### 会话保护

#### H02 新建及异步保护

通过标准：新建会话不会覆盖原会话；运行中禁止新建或选择历史；停止结算后可切换，迟到响应不进入另一会话或项目。会话操作与保存串行，失败时原可见会话保留。

验证结果：通过。两助手运行期间新会话按钮实际禁用，新会话不替换旧记录；Builder 新会话真实合成请求仅 system/user，不带 LEGACY-ONLY。会话切换由 active/operation/ioBusy ref 锁保护，项目和 controller 绑定与文本存储严格校验结合普通不同作品读回证明直接边界。未通过组件状态注入或绕过 Native 执行入口。

#### H03 迁移、失败及权限边界

通过标准：合成旧 `coding-chat/v1` 首次读取迁入索引及正文，迁移前原文件保留；无法读取、格式错误或保存失败时不以空会话覆盖旧资料并给出提示；历史尚未就绪时不能启动无归属的 Agent 运行。旧候选仅展示文本，不恢复可执行候选、文件授权或 Host 执行权限。

源码审阅发现：Agent 原 `useStudio.run` 与 `canRun` 未检查 `agentChat.ready`，读取未完成时 `useChatHistory.update` 会丢弃消息，运行可能使用空 `activeId`。已交主 Agent，当前开发源码读回已增加主入口及 `canRun` 的 ready/switching 锁；普通包复验仍待冻结来源。Builder `generate` 已有历史就绪检查。

其他源码边界：保存队列串行，迁移完成后才暴露旧消息；索引/正文严格校验项目、助手与会话 ID；重开把 proposed 降为 stale，没有还原候选执行权限。Builder 请求绑定 controller/project/chat，运行期间会话切换受 ref 锁保护。当前兼容 `coding-chat/v1` 只在消息 update 时投影，单独选择旧会话/新建不会立即更新该文件；GUI 读取索引正文且发请求显式带当前消息，尚无证据证明这导致 GUI 串会话，不把该投影称与当前选择始终同步。

验证结果：通过。旧合成 v1 在首次 UI 读回并保存为独立索引及会话正文。run4 对本任务索引文件持有真实 Windows 独占读句柄，真实新会话写入失败：UI 告警、原选中会话保留、原索引字节一致；释放句柄后重试成功且保留旧条目。run6 合成损坏索引打开后提示、Agent 输入及两个运行按钮禁用；F5 不启动、文件不变，正常退出仍不覆盖。候选权限边界以冻结源码严格文本 Schema/重开 proposed→stale及主 Agent 开发测试为补证，不外推任意旧权限恢复。
