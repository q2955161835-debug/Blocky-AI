## 发现和修复

- 初始契约测试缺生成的 runtime worker；按原构建方式生成后通过，没有删除平台限制。
- 独立复核发现小窗口预览先处理整篇文本。新增实际工作量回归先失败，再将分段器改为流式窗口、可取消和 maxChunks；预览达到 20 即停止，完整同步仍处理全文并传递 signal。
- 独立复核发现撤权后仍显示旧预览。真实组件回归先失败，再于版本改变清空预览；跨项目迟到结果复核通过。
- 质量子报告原忽略 denied，现显式 deniedFailures 并影响 passed；外层原已有泄漏检查，因此此项是子指标一致性修复。
- 整合发现新服务遗漏 Rust 白名单；新增跨 RemoteRuntime 的真实协议/白名单回归后补齐。检查源模型目录链接的用例先失败，现拒绝源目录链接。独立复核随后发现顶层准备会在拒绝前下载；共享 ensureAsset 现于校验/下载前检查全部父目录，verifyAsset 拒绝叶链接/硬链接。新的真实链接测试确认下载次数为零、链接目标未写入。
- 追加默认模型测试曾错误把允许保存的秘密引用 ID 当凭据。依现有正式资源契约修正测试为验证用户资源定义不复制、仅保存引用；未删改凭据边界。
