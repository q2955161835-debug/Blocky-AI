## 当前设置及消费者

| 设置 | 默认值 / 作用范围 | 实际消费者 | 验证入口 |
|---|---|---|---|
| models.defaultResourceId | 空引用 / 应用 | useStudio 新建项目、BuilderPanel、CLI builder | settings-core/default-model、component/default-model、cli/default-model |
| ui.reduceMotion | false / 应用 | useSettings preferences、画布状态投影 | settings-core/settings、原生画布 |
| ui.view | professional / 应用 | useSettings preferences、目录投影 | settings-core/settings、cli/foundations、原生视图切换 |
| window.minimizeToTray | true / 应用 | preferences → 原生窗口生命周期 | settings-core/settings、原生最小化与退出 |
| terminal.outputBudgetBytes | 65536 / 应用、项目 | useTerminals、useTask | settings-core/settings、cli/foundations、终端/任务预算；实际终端 4 KiB–4 MiB |
| logs.retentionDays | 7 / 应用 | useLogs configure | settings-core/settings、日志保留与清理；0 不保留历史 |
| logs.maxStoredBytes | 10485760 / 应用 | useLogs configure | settings-core/settings、日志预算；另受 100000 条/25601024 字节保护 |

`packages/settings-core/src/definitions.ts` 当前 7 项都有消费者。`useSettings` 迁移旧 preferences，损坏时保留原配置并提供恢复默认；reset 恢复继承。应用设置通过 Host user state 保存，项目终端覆盖由项目 settings 持久化；默认模型只引用本机资源，不覆盖已有项目。密钥和私有端点由安全存储持有，不属于设置值。
