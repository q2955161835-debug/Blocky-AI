## 开发问题与修正

- 校验后卸载中断、下载挂起时取消延迟已修复并有行为测试。
- 本地构建助手最初返回纯文本或不符合意图的工具，均由护栏拒绝；修正工具可见范围和 Schema 属性名验证后取得实际有效结果。
- CLI 旧工具示例读取了用户本机默认在线模型，在 simulate 下正确返回 `BLK-PROVIDER-DISABLED`。测试改为独立资料根，定向 4/4、完整 107/107 通过；个人默认设置未改变。

- 独立 Agent 重现 CLI 取消安装后遗留约 43 MB 工件。增加协作取消协议及临时清单恢复：真实复制期间 AbortSignal 返回后立即读回无残留；客户端断开同样无残留；强杀后 status 识别半成品、cleanup 完成受控清理。7 个相关 Rust 测试、25 个 CLI/组件测试、typecheck、release CLI 构建及桌面 Host 编译检查通过。开发证据在 `try/agent-capability-upgrade/dev-cancel/`，仍待独立复测。
