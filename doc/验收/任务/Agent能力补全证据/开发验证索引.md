## 开发问题与修正

- 校验后卸载中断、下载挂起时取消延迟已修复并有行为测试。
- 本地构建助手最初返回纯文本或不符合意图的工具，均由护栏拒绝；修正工具可见范围和 Schema 属性名验证后取得实际有效结果。
- CLI 旧工具示例读取了用户本机默认在线模型，在 simulate 下正确返回 `BLK-PROVIDER-DISABLED`。测试改为独立资料根，定向 4/4、完整 107/107 通过；个人默认设置未改变。
- 自定义公网首轮解析失败，重试独立同一公开请求成功；保持 TLS、公网地址钉住及取消限制，没有放宽网络权限。
- 独立 Agent 发现 CLI 误将 `localRuntime.contextTokens` 数值脱敏。新增失败用例后修正共享脱敏白名单，保留数值范围和类型限制；CLI 与事件总线的秘密字符串、对象、异常数值及相似未知键负例继续通过。定向 10/10 通过并重建 CLI，交独立 Agent 复测。
