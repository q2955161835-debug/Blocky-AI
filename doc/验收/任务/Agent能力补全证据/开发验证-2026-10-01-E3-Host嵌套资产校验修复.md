# E3 Host 嵌套资产校验修复开发证据

这是实现者的开发验证，独立阶段复验由另一 Agent 执行；不作为正式验收结论。范围仅为 `apps/studio-host/src/agent_data/evaluation_store.rs` 及其内置测试。最新 debug helper 于 2026-10-01 15:25 构建，用于原生开发探针；未构建 release 或 CLI。

## 修改与边界

Host 在 preflight、manage 和账本加载时自行验证资产，不依赖 WebView 或 TypeScript 已验证。按 `packages/runtime-core/src/evaluation/schema.ts` 的实际对象逐层限定 report、checkpoint、rows、checks、generations、usage、metrics、scoring、model、human、cases 和 modelScoring 的字段与类型，拒绝未知嵌套字段。实际 checkpoint 契约没有 inFlight 或 activeCaseKey，不接受猜测字段。

校验同时覆盖有界 ID、整数与时间、SHA256 格式、分数、错误码、摘要计数与 Token 汇总、结果 caseId 绑定、重复案例及 completed/partial 状态约束。原 CAS、冻结/完成不可变、项目隔离与原子替换仍保留；拒绝请求不新增资产、不覆盖旧账本。现有被污染账本加载时 fail closed，不自动迁移或删除用户数据。SHA 校验在这里验证声明格式，不宣称对业务结果重算内容摘要。

声明的 structuredResult 在 structured 策略下仍允许普通业务字段 answer/input，并按原值往返；summary 策略拒绝该字段。结构化结果按现有 `packages/observability/src/redact.ts` 的秘密字段/字符串模式和有界输出规则验证：拒绝未脱敏凭据、秘密模式与私有 Windows 路径，允许已经脱敏的字段和合法数字 Token 计数。Rust Host 没有可直接复用的对应结构化脱敏函数，因此在本 store 内对齐规则，未改变 TS 契约。相较裸 z.json，这里明确要求持久化结果已满足脱敏边界；并非禁止普通业务字段名。

dataset 的 input 和 expected.structured 仍是用户主动提供的素材 JSON，不套用 report 的字段或正文限制。未将报告中的 answer/apiKey 未声明字段误当作 dataset 素材禁令。
