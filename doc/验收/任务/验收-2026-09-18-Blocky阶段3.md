## 详细报告

### S3-01 导入真实资料

#### 场景：添加文件、URL 与仓库来源

三种来源均真实读取，支持格式与拒绝格式明确；来源 ID 稳定，清理与分段保留行号/标题/URL/commit，HTML 内容不能执行；超大、编码错误、路径越界、链接跳转和不支持格式给可定位错误。证据为源文件摘要、来源/片段记录与桌面同步摘要；不以预置内容代替读取。

### S3-02 增量更新与删除

#### 场景：改一段、删一份文档、重复同步

新增/更新/删除/跳过计数可对账，未变化片段不重复解析/Embedding；旧正文及引用从新查询和相关缓存失效。提供前后片段摘要、索引版本、检索差异和幂等重跑证据。

### S3-03 权限及项目隔离

#### 场景：收紧 ACL 后查询、切换项目、伪造来源句柄

权限从 Host 可信上下文取得，不能由请求任意冒充；在候选、缓存、重排、引用、日志与工件中均无未授权正文。项目间不能借句柄、路径或工件引用串读。独立安全人员检查真实持久化与负例；只测前端隐藏不算通过。

### S3-04 同步恢复

#### 场景：解析/Embedding 部分失败，取消并重启

失败清单与重试范围可见，不把部分索引误报为最新；保留可读上一版本且标明状态，恢复不重复提交；损坏工件拒绝使用。记录事务状态、重启后的索引摘要和失败诊断。

### S3-05 关键词查询

#### 场景：中文、英文、精确术语与元数据过滤

关键词算法处理真实片段，Top-K、阈值、元数据过滤实际生效；结果顺序稳定且分数/候选数可解释。分别验证中文与英文，空查询和零命中有正常结果。

### S3-06 向量与混合查询

#### 场景：同义改写、模型更换、批处理失败

真实模型产生 Embedding，有模型版本/维度/索引一致性证据；更换维度需重建，缓存不能跨版本误用。向量、混合和关键词模式可区分；无模型/超时/错误显式报告，不偷偷退化后宣称向量成功。离线模型与远程 API 分开记账。

### S3-07 重排与引用

#### 场景：开关重排、缩小上下文预算、打开出处

记录排名变化与降级，候选数和上下文不超声明预算；摘录对应当前来源的确切位置，去重不丢定位；引用过期、原文删除和错误行号不得当成有效证据。

### S3-08 质量与无证据行为

#### 场景：冻结问题集与反例

已确认质量集至少 40 题：20 有答案题（中英、精确词、同义各有覆盖）、10 无答案题、10 越权题。数据与标准答案在调参前冻结，测试集不直接用于调参；记录 Recall@5、MRR、引用正确率。已确认有答案 Recall@5 ≥ 0.85、有效引用正确率 100%、无答案/越权返回受限正文为 0；不得以删难题通过。无证据明确澄清/拒答。模型摘录合成不冒充真实生成式 API 调用。

### S3-09 仓库与证据

#### 场景：选定公开仓库与本地快照后只读扫描

2026-09-18 用户已确认 U10 使用 Haystack BM25 子范围。读回真实 commit、子目录、许可正文及摘要、依赖声明/锁文件与源码符号定位；缺锁文件只能报未锁定，不能伪造解析完成。工作树变化明确告知；扫描不改源仓库，不执行代码、Hook、安装脚本或自动子模块。扫描前后原仓库状态相同。

### S3-10 转换决策

#### 场景：库、流程、Harness 及不可安全解释部分

至少四类输入覆盖自定义积木、蓝图、兼容草案、原生保留决策，依据实际符号/接口/数据流/副作用与许可证证据；缺证据明确保留/阻塞。每个可运行产物有输入输出、权限、错误与依赖验证，至少一个真实转换产物可执行且对照结果一致；不得用名称匹配或固定模板假装完成任意项目转换。

### S3-11 转换审阅

#### 场景：查看幽灵差异，拒绝、接受及撤销

Build Spec、可见语义差异、权限增量与源码位置一致；生成/拒绝前后项目字节不变；接受基于最新摘要、原子应用且可整体撤销；过期候选、越权与非法补丁不写项目。接受后可编辑、编译、运行并保存重开。

### S3-12 增量扫描与大工件

#### 场景：改变单个文件、取消重启、升级上游

未变化文件按摘要复用；新 commit 重新核验证据与许可；取消/恢复不损坏缓存或重复副作用。大型 AST/证据留受控存储，CLI JSON 返回引用、大小和 SHA-256；篡改引用拒绝使用。上游升级展示差异并保留用户改动。

### S3-13 四个蓝图与首次任务

#### 场景：首次使用者选蓝图并修改角色/知识/工具

四个蓝图各有独立目标和真实可用流程；资料与代码引用可打开、知识小老师权限/缺证据策略生效、轻量任务使用受控工具。交互任务能引导完成运行并说明轨迹。普通包操作与目标年龄用户试用分开记录；目标年龄已确认 10–15 岁；用户暂无法安排参与者，此子项保持未执行，无参与者不得写目标年龄门禁通过。

### S3-14 蓝图生命周期

#### 场景：插槽绑定、展开、更新差异、恢复默认

必需外部依赖转公开插槽或阻止保存；缺失/类型错绑定有定位；展开后的原子语义等价；官方更新保留用户差异，冲突需显式处理，还原仅作用指定蓝图且可撤销。v1alpha1 到 v1 显式迁移不损坏原件。

### S3-15 个人蓝图与视图

#### 场景：Shift 点击/框选多栈并保存、重插、切换入门/专业

实际鼠标验证多选，保留相对布局，插入新 ID 无冲突；保存重开一致、展开/折叠不改运行；两视图切换前后 Workspace/IR 语义一致。键鼠操作不足时记录具体缺口，不以函数测试替代。

### S3-16 CLI 与桌面一致性

#### 场景：跨入口同步、检索、转换、插入蓝图与重开

同一输入/配置/存储产生相同语义结果，动态 ID 和时间做显式规范化比较；无入口专用业务副本。命令帮助、JSON/JSONL、退出码、取消和错误可用；打包后的 CLI 能读取桌面保存作品，反之亦然。

### S3-17 规模与长稳

#### 场景：小课堂、中知识库、大代码库与连续操作

已确认三档文本规模：100 文档/1 MiB、1,000 文档/10 MiB、10,000 文件/100 MiB；记录实际片段数与内容分布，不用重复空文件凑规模。每档至少 100 次查询，记录冷/热启动、首次/增量同步、P50/P95、峰值内存、索引体积与缓存命中。数据及模型版本和硬件记录在证据中。

已确认热查询 P95 上限为 500/1,500/3,000 ms（本地模型在内；模型冷加载另报）；取消确认 ≤ 2 秒，任务停止 ≤ 5 秒；峰值工作进程内存 ≤ 2 GiB（模型常驻另列），不含模型权重的索引体积 ≤ 语料 10 倍。10% 文件变化时，未变片段重嵌入数为 0。数据超过声明上限可明确拒绝，不能卡死界面。以上预算已在开发前确认，不能在失败后静默调宽。

原生 Full 保持 360 个五秒循环与 30 次真实 Host 保存重开；不能用缩短执行或旧阶段日志算本轮通过。
