## 详细报告

### S3-01 导入文件、URL 和仓库资料

#### 场景：真实读取、定位与拒绝危险输入

3A 领域与安全报告覆盖文本/HTML 分段、行号/标题、公开 URL、锁定 Git commit、编码/大小/路径/重定向负例。初轮发现 `git status` 会触发仓库 clean filter；修复后用同长度 dirty 文件重新执行，`filterExecuted=false`，锁定 blob 可读且缺失 promisor 对象拒绝，不再隐式 fetch。普通 GUI 选择 `lesson.md` 后读回 1 文档/1 片段，仓库转换也读回真实 commit、MIT 和文件行号。结果：**通过**。

### S3-02 增量更新与删除失效资料

#### 场景：修改、删除、重复同步与旧引用失效

失败来源误计删除的问题已复验为 `deleted=0` 且旧发布文档仍可读；正常增量的新增/更新/删除/跳过计数、未变内容复用和重复同步均有领域/CLI 证据。来源更新后旧引用返回 `BLK-KNOW-STALE`，不复活旧正文。三档 10% 更新均读回正确 updated/skipped；未变片段新增 Embedding 为 0。结果：**通过**。

### S3-03 修改资料权限并隔离项目

#### 场景：撤权、伪造身份和跨项目句柄

独立原生持久进程验证错误项目句柄、未知 principal、撤权后旧 generation、查询/Embedding 竞态和跨项目引用均被拒绝；撤权会使索引失效，旧缓存不能经公开入口重写或复活。结论限本机单用户信任模型，不扩写成多租户认证。结果：**通过**。

### S3-04 取消同步、恢复与部分失败

#### 场景：分页续传、重启、CAS 和损坏工件

初轮发现重启从首页读取及失败清单不可见；修复后 checkpoint 持久化 `cursor=1`/snapshot，重启只读取下一页，桌面组件显示来源名称、错误码和继续未完成来源。原生 5000 文件扫描跨进程取消 266 ms，真实推理取消 47 ms，stale CAS 和损坏对象均拒绝。结果：**通过**。

### S3-05 关键词检索

#### 场景：中英、精确词、过滤和零命中

共享领域、CLI 与 GUI 使用真实片段，Top-K、阈值、元数据过滤、空查询和零命中均有明确结果。冻结质量集关键词模式 40 题，Recall@5=1、MRR=1，热 P95 19.88 ms；普通包查询可读回 locator 与候选数。结果：**通过**。

### S3-06 真实向量与混合检索

#### 场景：模型真实性、模式区别、错误和缓存完整性

候选 3 随包模型在未设置模型目录覆盖时加载 `multilingual-e5-small-int8-v1`，ONNX CPU、384 维、模型 hash/版本可读，`externalApi=false`。关键词、向量、混合三模式区分；缺模型、模型不匹配、超时回退均显式报告。初轮相同 offset/不同 key 可错误复用的问题已独立复验为 `BLK-EMBED-CORRUPT`，合法相同文本仍可复用。结果：**通过**。

### S3-07 重排、预算与引用

#### 场景：排名、预算、过期引用与打开出处

局部验收覆盖重排开关/降级、上下文预算、候选数、去重、行号以及来源修改后的旧引用拒绝。候选 2 GUI 能展开 `lesson.md:1–1` 摘录，CLI 在重开后读回同一 locator。产品契约要求同页“打开出处”区域；本轮没有实际点击该窄按钮并读回完整同页内容，不能以 CLI 或“没有独立系统窗口”替代。结果：**有条件通过**。

### S3-08 质量与无证据行为

#### 场景：冻结 40 题及受限正文

质量集为 20 有答案、10 无答案、10 越权，fixture SHA-256 固定。关键词/向量/混合三模式均为 Recall@5=1、MRR=1、有效引用正确率=1、受限正文泄漏=0；运行证据 `verifiedLocations=true`、`excerptOnly=true`。无证据通过澄清边界处理，原文摘录不冒充生成式回答。结果：**通过**。
