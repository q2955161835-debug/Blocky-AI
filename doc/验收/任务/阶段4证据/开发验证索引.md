## 错误与边界

原生首轮固定点击点被积木覆盖，按实际命中背景定位后通过。版本升级遗漏 Host 补丁目录限制，补齐当前版本、新积木目录/权限与读取版本后通过；没有放宽旧批准和权限标准。API 首次返回未授权引用，按预期拒绝；下一次公开夹具单独登记后成功，不是隐式重试。

工具首批只有登记的本机文本统计；模型首批只有 DeepSeek 官方文本协议和本地整理器。记忆是显式键值，引用核验不等于开放域事实正确性；预算预留保守扣除且失败不退还。完整构建助手、RPA、官方 Skills、其他供应商等不在阶段 4 交付内。未新增任意 Shell/文件端口、复制旧尖峰或旁路审批；尚无本阶段已知待还的临时绕行实现。

## 最终源码修复复验

独立检查发现两个模块调用同一模型块会复用请求编号，导致 Host 单次批准账本拒绝第二次合法请求。`f24aea0` 为模型和知识调用增加共享调用预算中的单调序号，事件开始/完成及响应保持同一编号。正式回归先失败（唯一编号 1，预期 2），修复后通过；独立捕获探针 2/2 通过。最终源码 `pnpm check` 退出 0（185 单元、27 契约），组件 24/24。普通包、原生 E2E 与 Full 须绑定此修复后的来源，早期候选只作历史证据。
