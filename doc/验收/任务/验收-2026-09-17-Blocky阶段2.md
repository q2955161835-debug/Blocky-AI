## 详细报告

### S2-01 迁移并保存旧作品

#### 使用场景：尖峰单画布、阶段 1 多画布和失败迁移

显式迁移至 v1 的新文件；保留原始文件、稳定块/模块 ID、导出与资源引用和可表达的运行语义；成功迁移可重复得到相同语义摘要。未知版本、未知语义、损坏包、冲突输出、迁移中断必须提供定位诊断且不产生可误认为完整的新包。正式普通打开入口拒绝尖峰内部格式。保存重开须重新生成/比对派生 IR，Host 原子保存仍有效。证据：原件/结果哈希、迁移报告、当前 CLI/Host 及普通桌面读回。

### S2-02 多画布语言与增量编译

#### 使用场景：改名、删模块、改导出和局部修改

同一项目多次生成稳定 Module/Project IR、source map、InteractionManifest/ToolContract；跨模块引用按 moduleId/exportId 定位。改名不破坏连接，删除或类型变化在调用块显示诊断，同步环不执行。增量与全量编译等价；未变化且依赖未失效的模块不重编译，Schema/导出/目录变更不能遗漏失效。证据：黄金夹具、摘要、失效集合与实际错误定位；不以仅缓存计数证明正确性。

### S2-03 从各入口执行统一命令

#### 使用场景：菜单、命令中心、右键与快捷键

文件/编辑/视图/运行/构建/帮助第一批命令具有同一 ID、可用性和执行结果；不可用项显示原因。菜单保持锚点下拉，命令中心独立，右键遵循选择上下文；弹层互斥，Escape/外点关闭和焦点返回正确。文字输入、终端和浏览器不会被画布快捷键抢占。证据：组件行为及普通应用操作；不接受四份重复执行逻辑。

### S2-04 连续编辑、撤销与重做

#### 使用场景：跨画布编辑、粘贴/蓝图/补丁和保存点

一次用户语义操作形成一个事务；撤销/重做恢复布局、稳定 ID、资源和跨模块关系；新编辑清除旧 redo，保存点 dirty 正确。切换标签、运行及多轮编辑不损坏撤销栈。保留框选/Shift 多选、中键平移、指针缩放和搜索既有行为。证据：前后项目摘要、真实输入/可见画布，以及长稳中撤销场景。

### S2-05 工作台布局与标签会话

#### 使用场景：新建/关闭/恢复画布标签及调整底部面板

标签创建、关闭、重新打开、排序和最近使用切换可用；关标签不删模块或页面。三栏及底部面板可调尺寸、停靠/展开/最大化/折叠，问题/运行日志/终端/输出状态恢复正确。视口、布局、筛选与终端布局不改变项目语义；不存在的会话目标提供诊断并安全回退。证据：重启读回与项目语义哈希。

### S2-06 查找、继承、保存及重置设置

#### 使用场景：应用与项目覆盖、资源/积木来源显示

搜索来自 SettingDefinition；默认值、校验、来源、恢复继承和作用域存储一致。用户修改后实际消费者生效；重启要求明确。应用设置不污染项目，项目设置可随作品重开；版本迁移或损坏配置不能静默吞掉用户值。仅展示真实消费者，无秘密配置进入普通字段。证据：Schema/存储/界面三方对照与重开测试。

### S2-07 修改快捷键并处理冲突

#### 使用场景：主/备用绑定、同域冲突、恢复默认及配置往返

命令使用完整计划 9.4 的本阶段适用默认绑定；Ctrl+Shift+Z、另存为、标签等绑定有效。冲突依据命令上下文识别，系统/WebView 保留组合有提示，导入不会静默覆盖既有键位；重置后恢复相同命令来源。后续阶段尚无消费者的调试绑定不得冒充可用。证据：冲突矩阵、配置往返和真实键盘行为。

### S2-08 管理资源与切换积木分类视图

#### 使用场景：各资源类别、不同 scope、删除引用和秘密绑定

model/knowledge/memory/tool/skill/mcp/guardrail/data/task 有类型化定义与引用校验；创建、配置、改名、删除及引用影响可理解，user/project 同名不回退。敏感字段仅 Host 安全存储或忽略的本地配置，作品/蓝图/IR/日志不带明文。专业十二类与入门七类共享同一目录，视图切换不改 ID/IR；不要求在本阶段执行未来 Provider/RAG/MCP 功能。证据：用户操作、领域负例、虚构 canary 扫描。

### S2-09 使用真实用户多终端

#### 使用场景：两个独立交互终端、resize、前台程序与关闭

在普通应用真实创建 Windows PTY，用户输入/交互/终端控制序列可用，两个会话状态隔离，调整尺寸生效；面板隐藏不停止程序，关闭有前台程序时明确选择。大输出有界、截断可见且画布保持响应。历史和输入不写入项目；重启不自动重放命令。证据：PTY 原生状态、交互式测试程序和普通 UI 行为；stdout 文本模拟不合格。

### S2-10 运行受控具名任务和 Agent 进程

#### 使用场景：登记任务、参数限制、并发/取消与越界请求

任务按可执行文件/目录引用和参数 Schema 运行；有环境白名单、能力授权、输出预算、超时、队列/拒绝策略及进程组终止。用户 PTY 与任务/Agent 进程物理隔离；Agent/Builder/Skill/扩展/RPA 读取、附加、输入或继承用户 PTY 均在副作用前拒绝。非法参数、命令拼接、越界路径和未经授权任务负例有稳定错误。证据：独立安全测试、进程树及取消/超时读回。

### S2-11 阅读、保留、清除及导出日志

#### 使用场景：结构化投影、压力、持久保留和诊断导出

Diagnostic/RuntimeEvent/LogEnvelope 分别驱动正确视图；登记通道、序号/关联 ID、筛选与源位置有效。先脱敏再入总线、磁盘和导出；分块/大输出不能泄漏 canary 或阻塞管道，截断/丢弃和重要日志损失有结构化记录。清视图不误删存储；保留周期/容量、清存储审计、损坏记录隔离和显式导出范围实际生效。默认导出排除用户输入、环境值和敏感正文。证据：压力数据、存储读回与独立安全负例。

### S2-12 使用项目隔离的应用预览

#### 使用场景：默认零页面、显式创建/拒绝、两项目预览和关闭

保留页面候选审查与权限决定；默认零 AppSurface，拒绝无修改。桥接仅调用声明入口，禁止越界导航和未授权能力，项目间 Cookie/存储/消息不可串读。关标签释放预览资源但不删除源文件；保存重开正确。证据：普通页面问答及跨项目存储/桥接独立安全负例；测试 iframe 隔离不能冒充原生隔离全通过。

### S2-13 管理窗口、通知区域和真正退出

#### 使用场景：最小化、恢复、第二实例、显示器变化和退出

最小化默认通知区域，设置可切换任务栏；关闭、隐藏继续、停止退出含义清楚。第二实例恢复原窗口，窗口位置/DPI/屏幕变化后可访问。真正退出结算 PTY、任务/子进程、Agent 进程、预览、日志句柄和刷新器；隐藏不冒充退出，新任务遵守 Host 策略。证据：普通窗口/托盘操作和退出前后进程、句柄等资源读回。

### S2-14 从崩溃和损坏会话恢复作品

#### 使用场景：未保存作品恢复、坏会话/设置和旧版本升级

崩溃后明确提示恢复副本和原保存状态，用户选择恢复或放弃；不能将过时恢复档静默覆盖新作品。恢复工程仍重编译验证；会话/设置错误给诊断，不自动重新运行 Agent、PTY 命令或外部任务。证据：可控故障、原件/恢复件哈希和重新启动旅程。

### S2-15 从 CLI 使用相同领域能力

#### 使用场景：能力发现、迁移/模块/设置/资源/任务/日志操作

本次已经实现的领域能力从 CLI 可发现并使用，共享校验器/迁移器/编译器/权限接口；JSON/JSONL、退出码、取消、输出冲突和无副作用拒绝一致。包装后跨目录使用可成功，不依赖工作区源码。CLI 不提供附加、读取、操纵用户交互 PTY 的接口。以跨端结果摘要验证一致性，不把 CLI 代替鼠标或通知区域验收。

### S2-16 接收可复现的普通 Windows 成品

#### 使用场景：当前候选完整旅程、Core/Full 与发行包

从普通成品完成创建多画布→编辑/资源配置→运行确定性问答→真实终端/具名任务→日志/诊断→保存重开→托盘恢复→退出的代表性旅程。新旧必要场景有证据；Core 与完整 360×5 秒、30 次真实保存重开 Full 绑定当前源码，失败不能忽略或缩短。普通包不含测试钩子、远程代码、秘密、本机私密路径及内部过程资料；许可证来源完整。记录精确提交、命令/退出码、字节数/哈希、未执行项和残余风险。真实 API 明确为否；旧候选不覆盖，合并/推送状态分别汇报。
