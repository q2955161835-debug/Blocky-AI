## 详细报告

### 1. 注册协议与固定执行边界

`packages/terminal-protocol/src/project-check.json` 登记了唯一任务 `blocky.project-check`。其输入只有 `passes` 和 `interval-ms` 两个数字参数，分别限制为整数、1–360 和 0–1000；请求还限制 `timeoutMs` 为 1–30000、`outputBudgetBytes` 为 256–65536。登记信息固定 executable reference、项目工作目录引用、空环境键、空 secretRefs、Windows 平台、最大并发 1、200ms 取消宽限和成功退出码 `[0]`。

`packages/terminal-protocol/tests/task.test.ts` 真实调用 `parseTaskRequest`，确认越界、浮点、额外参数、cwd、environment、过大输出预算、零超时和未知 taskId 都返回 `BLK-TERM-101`。同一文件逐个尝试 builder、agent、skill、extension 和 rpa 的用户终端附加请求，均返回 `BLK-TERM-003`。请求协议使用严格对象结构，没有 command、cwd、environment 或终端句柄输入位。

- `task run <project> --passes 3 --interval 1 --timeout 30000 --output-budget 256 --json` 返回码 0；结果为 `status=exited`、`exitCode=0`、`activeProcesses=0`、`outputBytes=256`、`droppedBytes=74`、`truncated=true`，保留输出含三次检查的结构化进度前缀和 `valid:true`。

`tests/cli/tasks.test.ts` 的两个测试通过现有 `helper` 解析路径实际 spawn 原生 companion：正常 bounded child 结算为 `exited/0` 并读回截断；Abort 取消与 deadline 超时均在 `activeProcesses=0` 后才返回。该测试没有使用 fake child 或只检查 CLI 文案。

### 3. Host 任务进程和隔离

`apps/studio-host/src/task_host/process.rs` 固定以当前 companion executable 启动 `--blocky-task-worker`，使用 piped stdin/stdout、丢弃 stderr、清空环境，并在 Windows 下挂入 Job Object，使子进程组在句柄关闭时终止。任务 worker 只输出包含 `pass`、`fileCount`、`valid` 和固定检查码的结构化进度，不回显项目源码、输入或环境。

任务输出按字节预算读取并持续排空 child stdout；结果记录 `outputBytes`、`droppedBytes` 和 `truncated`。取消或超时先发送固定 `cancel`，等待登记的宽限期后终止 child，并在快照中将 `activeProcesses` 置零。真实 CLI 结果和聚焦测试共同覆盖成功、截断、取消、超时和最终结算。

`TaskHost` 从登记定义重新校验 taskId、参数、超时和预算；同一 Host 存在活动进程时返回 `BLK-TERM-103`，任务请求数量有上限。`apps/studio-host/src/task_commands.rs` 只接受主窗口任务入口，状态和取消按 requestId 查询，未声明的 `attach_user_terminal` 无条件返回 `BLK-TERM-003`。本轮读取并核对这些边界，没有启动 Tauri 窗口；主窗口可见性、最小化、后台运行和退出结算留给 S1-09。

### 4. `useTask` 与 `TaskPanel` 组件

临时 jsdom 探针通过 alias 注入 Tauri `invoke` Mock，只验证组件/组合逻辑，不冒充桌面视觉：

- `useTask.start()` 使用协议解析和 `encodeProject` 生成请求，调用一次 `start_task`，将底部面板切到终端；随后轮询 `task_status`，收到 `activeProcesses=0` 的 `exited` 快照后释放 requestId、pending/gate，并通过 `studio.bus.write` 写入结构化 terminal 记录。
- `TaskPanel` 在完成状态显示“检查通过”、退出码、输出内容和“输出已截断，省略 N 字节”；活动任务时运行按钮和四个参数输入禁用，停止按钮可用。

组件探针执行退出码为 0，2 个测试通过。它没有验证原生模态、窗口绘制、焦点、DPI、通知区域或普通 Windows 视觉。
