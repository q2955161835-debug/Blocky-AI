## 详细报告

### 1. 模型配置

#### A01：选择原有、自定义和本地生成后端

验证 DeepSeek/息壤旧资源、新自定义兼容服务、已有本地服务和 Blocky 管理的本地生成进程均能完成实际生成；资源保存重开、默认继承、流式/结构化能力按声明工作。不支持能力明确报错。检查端点绑定、凭据隔离、认证失败、超时、取消及用量记录；错误不回显秘密。托管模型有实际安装/校验/移除、负载控制和进程退出证据。本项负责模型传输与资源契约。

### 2. 知识模型

#### A02：更换嵌入与重排模型

实际运行原 E5 和至少一个可替换嵌入后端；实际运行一个神经重排模型。索引保存模型/维度/版本签名，切换后重建并原子启用；中途取消、工件损坏、维度不符和回退均有明确结果。规则重排与模型重排区分呈现。本项负责模型工件和索引兼容，不重复资料问答质量项。

### 3. 文档导入

#### A03：解析普通文件与扫描资料

中英文 PDF、DOCX、XLSX、CSV、图片和扫描 PDF 的代表性文件均实际解析；正文、表格和引用位置可核对。扫描资料确实执行 OCR。坏文件、受保护文件、超大/异常压缩文件、缺少 OCR 资源有明确失败或修复路径，不静默当空文档成功。

### 4. 知识摄取

#### A04：编辑摄取流程并更新资料

普通用户可用默认蓝图完成来源→解析→分段→嵌入→索引，高级用户可展开修改并保存重开。分段预览与实际索引一致；增量更新、删除、撤权、失败续传与重复同步保留准确来源和状态，不破坏上一个可用索引。

### 5. 资料问答

#### A05：检索、自我纠正与引用

同一公开资料集建立 20 个有证据问题和 10 个无证据问题；关键词/向量/混合配置可对比。约定有证据问题的正确来源 Top-5 命中不少于 18/20；无证据问题至少 9/10 明确不足或澄清。引用链接/定位有效，非法引用被拒绝。弱检索可触发有界改写和重新检索；准确记录实际次数。测试集和指标在执行前冻结，不能删困难样例提升成绩。

### 6. 自主办事

#### A06：模型决定下一步并完成多轮任务

同一任务至少完成两次实际工具调用，后一步参数依赖前一步实际结果，再由模型结束；工具轨迹与结果可读。验证有界循环、逐项处理、条件分支、错误重试、总预算、取消、重复调用和恢复。固定预排工具顺序不能替代自主选择的证据。本项负责执行语义，传输与工具适配分别见 A01/A07。

### 7. 工具连接

#### A07：连接项目工具、HTTP 和 MCP

项目模块工具和受控 HTTP 实际返回结果；MCP stdio 与 Streamable HTTP 完成协商、发现、调用、资源读取和停止。Schema、参数、错误和来源可检查；非法目标、失效凭据、服务退出、越界资源和权限拒绝均受控，所有子进程能回收。

### 8. 长期记忆

#### A08：保存、查找和管理记忆

会话与项目记忆支持实际搜索、来源查看、摘要、过期和删除；同键冲突策略明确。跨项目/用户隔离，进程重启后保留允许持久化的内容；删除/撤权后检索不再返回旧内容，失败写入保留一致状态。

### 9. Skill

#### A09：发现并按需使用 Skill

能发现资源元数据、按需加载正文与受控附属资源，执行一个实际有用的 Skill 流程。版本与调用轨迹可核对；未使用的正文不无条件加入上下文。路径穿越、越权工具、附带代码和恶意指令不能扩大 Host 权限。

### 10. 多 Agent

#### A10：委派与汇总任务

完成实际顺序交接与并行子任务，输入/输出映射、汇总和失败策略明确。子 Agent 权限不超过获准范围，总预算跨子任务结算，取消及超时收敛，结果有独立来源，不把纯计算并行称为多 Agent 执行。

### 11. 学习式决策

#### A11：规则与实际模型协作

使用一个真实分类/评分模型，展示规则命中、模型推断与后备路径三种情况；输入字段、标签/分数、阈值、版本与实际推理记录可核对。非法输入、缺少模型和低可信结果按声明处理。本项不包含尚未确认的 JEPA 实模型承诺。

### 12. 自动触发

#### A12：定时与外部事件

实际定时和授权外部事件触发同一项目入口；时区、重启、错过时点、重复投递、去重和暂停有明确行为。事件认证和项目绑定有效，恢复不能重复已完成副作用，退出行为符合应用配置。

### 13. 多模态输入

#### A13：图片与音频转写

用真实可用后端处理图片输入和一段音频转写，媒体引用、进度、结果和取消可读。文件选择、容量、格式错误、媒体保留/删除与凭据边界明确；无能力后端不会把未处理的媒体当成功结果。

### 14. 效果评估

#### A14：建立测试集并比较作品

用户可创建/导入数据集、冻结版本、批量运行、取消续跑、查看逐例错误和汇总、比较两版作品。确定性指标能手工复算，模型评分和人工评分分别标明，配置与模型版本绑定结果；报告不包含秘密。本项验收评估工具本身，A05 的质量集作为可复用输入。

### 15. 搭建与操作

#### A15：桌面、CLI 与构建助手使用同一能力

新功能均有可发现命令/Schema、结构化状态、错误与恢复路径；普通桌面提供对应配置和可检查结果。构建助手能搭建三个核心作品，补丁可审阅、拒绝、接受、撤销和保存重开；缺少配置明确指出。本项检查入口和组装一致性，引用各领域通过证据，不重复全部业务场景。

### 16. 升级与稳定性

#### A16：旧作品与核心交互持续可用

旧项目/蓝图升级保存重开不丢编辑事实，旧资源不隐式联网或换模型；工作区布局、默认模型、画布输入、轨迹、审批、应用界面与 RPA 直接影响流程通过。执行适用完整 Core 与未缩短 Full：360 个 5 秒循环、30 次真实 Host 保存重载；定位长期状态、事件和内存异常。

### 17. 安装与交付

#### A17：交付普通包并正常退出

最终目录与已验候选逐文件哈希相同，依赖和模型许可证完整，普通包不含测试钩子、内部验收材料或秘密。项目、前端、Host、诊断导出四目标扫描通过；真正退出回收本轮 worker、MCP、预览和运行任务。固定桌面入口切到已验版本并读回，旧包可回退。
