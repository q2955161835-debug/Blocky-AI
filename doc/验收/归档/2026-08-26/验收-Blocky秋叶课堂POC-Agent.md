## 详细报告

### 1. 可移植 Agent 项目

验证步骤：解包 `POC与演示视频/Blocky-秋叶课堂讲解-Agent.blocky`，读取 `manifest.json` 和 `project.json`；核对文档格式、项目 schema、项目 ID、根积木数量、聊天入口及接受能力。

预期结果：容器为 `blocky.document/v1`，项目为 `blocky.spike-project/v1`；项目 ID 为 `poc-autumn-leaf-lesson-agent`；仅有一个“秋叶课堂讲解 Agent”根和一个接受文本的“课程问答”入口；无路径穿越或额外文件。

当前结果：通过。产物 1,151 字节，SHA-256 为 `9547125ce978f3ba4565aa4cd71421d4c6a7eec4ac5c0e5f9c4b131a23dcd6cc`。

### 2. 指定聊天入口执行积木处理链

验证步骤：为运行请求传入选中的稳定入口 ID，执行“Agent → 课程问答入口 → 回复 → 创建消息 → 课程内容 → 发送 → 流式 → 等待”链；核对事件序列、回复来源和唯一终态。

预期结果：处理链中的每个块均有正确 `blockId` 的开始/完成事件；回复内容由 `core.data.literal` 经消息与回复块输出；最终只有一个 `run.completed`。运行过程中每个块保持激活至可视化节拍释放，取消时及时结算。

当前结果：通过。处理链正常输入依次产生来源映射事件与唯一 `run.completed`；独立验收发现带 `entryId` 的真实 UI 会绕过 `/error` 失败夹具后，新增 unit/controller 回归测试并先红后绿，当前 `/error` 路径为 `block.started → run.failed`，且不产生 `model.chunk`。

### 3. 60 秒单提示词演示

验证步骤：原生应用打开目标 Agent，右侧“对话测试”输入一次指定问题并发送，全程不切换窗口或二次操作；观察逐块绿色高亮和最终回答。

预期结果：一次运行在 60 秒内完成；回答包含课程依据 `[《秋天的叶子》§2]`、`[§3]` 与“待核实”；录屏可同时看清积木链、执行状态和回答。

当前结果：通过。Windows 原生 release 从目标目录打开产物，UI Automation 读回“已保存”、9 个积木和唯一“课程问答”入口；一次输入后现场轮询在 15.8 秒内读回精确完整回答，其中 8 个运行节拍配置为 `8 × 650 ms = 5.2 s`，满足 60 秒上限。回答、入口、画布和输入区可同时显示；运行结束后重新载入项目用于恢复录制起始状态。

### 4. 回归与边界
