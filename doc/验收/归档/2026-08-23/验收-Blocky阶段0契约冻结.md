## 详细报告

### S0-01 契约完整性

- 步骤：读取正式契约索引，确认登记的 Schema 均有正文、负责对象、存储边界、派生状态和首个消费者；解析本次 Markdown 相对链接。
- 预期：无缺失正文或坏链；公共类型、版本和迁移规则可定位。
- 命令：必需类型覆盖脚本、相对链接检查、严格 UTF-8 检查。

### S0-02 项目事实与会话

- 步骤：解析 `minimal-multi-module-project.json`，对照 ProjectManifest 和 WorkspaceSessionState。
- 预期：两个模块、各自 Workspace 摘要、一个知识资源、零 AppSurface；会话独立且不改变项目事实。
- 命令：JSON 解析与项目/会话字段断言。

### S0-03 链接与诊断

- 步骤：解析缺失导出负例，审阅稳定引用、同步环和异步预算规则。
- 预期：只产生 `BLK-LINK-002`，来源定位 `research-agent/call-citation`，不按显示名重连。
- 命令：负夹具代码和来源断言。

### S0-04 运行可观察性

- 步骤：解析确定性事件夹具并投影积木状态、运行日志和轨迹目标。
- 预期：序号唯一；含成功、警告和失败路径；绿/黄/红同时有粗描边、图标与文字。
- 命令：事件唯一性、失败事件和映射规则检查。

### S0-05 Builder 与应用界面

- 步骤：审阅 BuildSpec/SemanticPatch；比较显式和隐式 AppSurface 夹具。
- 预期：普通 Agent 请求保持零页面；显式请求接受后从 0 变 1；拒绝或错误不写项目。
- 命令：页面数量和 `BLK-SURFACE-001` 断言。

### S0-06 RPA 与窗口

- 步骤：对照 attended/unattended RPA 夹具和窗口生命周期夹具。
- 预期：v1alpha1 只接受 attended；坐标为 elevated 回退；退出资源计数全零。
- 命令：`BLK-RPA-001`、定位风险和结算计数断言。

### S0-07 终端隔离

- 步骤：审阅 TerminalSessionContract、TaskDefinition、AgentProcessRequest 和越界负例。
- 预期：Agent 请求不允许 `terminalSessionId`、PTY、原始命令、任意 cwd 或环境值，越界报 `BLK-TERM-003`。
- 命令：类型正文和负夹具字段/代码检查。

### S0-08 日志安全与生命周期

- 步骤：审阅 LogEnvelope/AuditRecord、保留类、导出和退出结算；解析未脱敏日志负例。
- 预期：先脱敏后分发；复制/导出二次脱敏；未脱敏值报 `BLK-LOG-004`；敏感扫描无真实匹配。
- 命令：负夹具、敏感模式和保留/退出关键词检查。

### S0-09 阶段 1 追踪

- 步骤：审阅阶段 1 正式接口交接矩阵。
- 预期：U01–U07、U15、U16、U18、U19 都映射到契约、正反夹具、最小实现、适配器、真实替换阶段和人工流程。
- 命令：旅程编号、十夹具和阶段 2–9 替换覆盖检查。

### S0-10 当前状态真实性

- 步骤：扫描正式契约和当前基线文档的临时产品字段、旧产品称谓、固定总数和实现状态。
- 预期：无阶段专用项目/UI 字段，无把兼容模板称为运行方案，无固定积木总数；阶段 1 与真实能力保持未实现。
- 命令：禁止项扫描、状态冲突扫描、`git diff --check`。
