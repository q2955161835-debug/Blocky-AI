# 首次停止失败保留

来源：1d29f2756204eca5d2be54a665be6dc0b85855f9。独立浏览器连续两次复现。

路径：工作助手起点 → 构建助手发送草稿 → 首条回答出现 → 点击底栏“停止演示”。第一次在已通过手模式平移检查后执行，第二次同样复现。

结果：iframe内整页空白；读取 `.builder-chat-message-assistant` 超时。浏览器 pageerror 为 `Minified React error #31`，其对象参数包含 `_reactName, _targetInst, type, nativeEvent, target, currentTarget, eventPhase, bubbles, cancelable, timeStamp, defaultPrevented, isTrusted, view, detail, screenX, screenY, clientX, clientY, pageX, pageY, ctrlKey, shiftKey, altKey, metaKey, getModifierState, button, buttons, relatedTarget, movementX, movementY, isDefaultPrevented, isPropagationStopped`。

原始原因：底栏直接 `onClick={running ? stop : undefined}`，鼠标事件作为 `stop(message)` 的参数进入 `setStatus(message)`，React尝试渲染事件对象。

独立验收已即时通知主Agent。旧来源本项不通过。后续用 `()=>stop()` 修复并在 b2f7549c2bf5393d4c9ece29deae4fe924de582c 复测。后续脚本时机调试曾覆盖通用 failure.png/failure-errors.json，故不把这些现有文件冒充原始失败截图；本记录保留实际工具输出中的错误与两次复现事实。验收过程脚本修正仅涉及locator和停止时机，不修改产品实现。
