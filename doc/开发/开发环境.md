# Blocky 开发环境

## 当前范围

本阶段已准备 Windows Core 及未来 Android、HarmonyOS 使用端需要的系统工具链和可复现检查入口，尚未创建业务代码、`packages/cli`、正式 Agent Skills 或跨平台工程骨架。Android 与 HarmonyOS 工具链的存在仅表示本机具备后续验证条件，不代表这两个平台进入首发，也不代表它们提供积木编辑器。Tauri、Blockly、React 等项目依赖应在对应 `try/` 技术尖峰开始时安装，并在尖峰通过后再锁定正式工具链版本。

## 本机已验证工具链

| 平台 | 工具 | 当前验证结果 |
|---|---|---|
| 通用 | Git、Node.js、pnpm、Rust、Cargo、rustup、JDK 17 | 可用 |
| Windows | Visual Studio 2022 C++ Build Tools、Windows SDK、WebView2 Runtime | 可用 |
| Android | Android Studio、API 36、Build Tools、Platform Tools、Command-line Tools、NDK r29 | 可用 |
| Android/Rust | `aarch64`、`armv7`、`i686`、`x86_64` 四个 Android targets | 可用 |
| HarmonyOS | DevEco Studio 6.1.1.300、HarmonyOS 6.1.1/API 24 SDK、ohpm、hvigor、hdc | 可用 |

本机工作区外的工具链位置：

- Android SDK：`D:\Android`
- Android NDK：`D:\Android\ndk\29.0.14206865`
- DevEco Studio 与 SDK：`D:\Deveco_Studio\DevEco Studio`
- Rust Android targets：由 rustup 安装到当前用户的既有 rustup 工具链目录

`ANDROID_HOME` 与 `NDK_HOME` 已写入当前 Windows 用户环境变量。新终端会自动读取；已打开的终端需要重新打开，或点源环境脚本。

## 使用方式

在项目根目录打开 PowerShell：

```powershell
. .\scripts\use-dev-environment.ps1
.\scripts\check-dev-environment.ps1
```

第一条命令只修改当前 PowerShell 进程，把 Android 与 HarmonyOS 工具加入 PATH；不会永久改写 PATH。第二条命令执行只读健康检查，任一必需项缺失时返回非零退出码。

doctor 始终返回固定 26 项检查；父级 SDK 路径无效时，相关子项明确标记为 `FAIL`，不会从 JSON 中消失。它同时要求 Java 17 及以上、Android SDK Platform/API 29 及以上、Android Build Tools 29 及以上、HarmonyOS API 12 及以上，并校验外部版本命令的真实退出码。

机器读取可使用：

```powershell
.\scripts\check-dev-environment.ps1 -Json
```

修改环境脚本后运行契约测试：

```powershell
pwsh -NoProfile -File .\tests\dev-environment\doctor-contract.ps1
```

契约测试使用隔离子进程覆盖健康环境、无效 Android/DevEco 路径、失败版本命令、过旧 Java、进程级路径覆盖和缺失 NDK，不会改写用户环境变量或 SDK。
